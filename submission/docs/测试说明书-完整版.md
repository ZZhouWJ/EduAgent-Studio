## 1. 概述

### 1.1 项目简介

EduAgent Studio（智学工坊）是基于大语言模型的多智能体协作式个性化学习资源生成系统，采用 React 18 + Vite + TypeScript 前端 + FastAPI + Python 后端架构，围绕学生画像、多智能体资源生成、教师审核、学习效果闭环等核心场景，通过 LangGraph StateGraph 编排的 5 个智能体协作实现自动化学习资源生产。

### 1.2 测试范围

| 测试类型 | 说明 |
|---------|------|
| 接口测试 | 后端 RESTful API 功能与边界验证 |
| 页面功能测试 | 前端核心页面交互与数据渲染 |
| 智能体工作流测试 | LangGraph 多智能体协作链路验证 |
| 数据库测试 | SQL 脚本执行与数据完整性验证 |
| 端到端测试 | 完整业务流程演示验证 |

### 1.3 测试目标

- 验证系统满足 A3 赛题全部 16 项必做要求 + 2 项加分要求
- 验证教师端、学生端、管理端三套角色的功能完整性
- 验证多智能体协作、资源生成、效果闭环等核心链路的正确性
- 验证系统可部署、可运行、文档完整

## 2. 测试环境

### 2.1 软硬件要求

| 组件 | 要求 |
|------|------|
| 操作系统 | Windows 10/11 或 macOS / Ubuntu |
| 前端 | Node.js 18+ |
| 后端 | Python 3.10+ |
| 数据库 | MySQL 5.7+ |
| 向量数据库 | PostgreSQL 16 + pgvector（可选） |
| AI 能力 | Mock 模式（开发/演示）、真实 LLM 模式（OpenAI/Qwen/DeepSeek/MiniMax） |

### 2.2 快速启动

```bash
# 后端
cd backend
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000

# 前端
cd frontend
npm install
npm run dev
```

### 2.3 Mock 模式配置

在 `backend/.env` 中配置：

```env
LLM_PROVIDER=mock
LLM_MOCK_DELAY=0.5
```

# backend/tests/performance/test_concurrent_requests.py
"""
并发性能测试
运行方式：pytest tests/performance/test_concurrent_requests.py -v -s
"""

import pytest
import asyncio
import time
from concurrent.futures import ThreadPoolExecutor, as_completed


class TestPerformance:
    """性能测试套件"""

    def test_concurrent_agent_requests(self, client, auth_token):
        """并发请求测试：同时 10 个资源生成请求"""
        headers = {"Authorization": f"Bearer {auth_token}"}
        base_url = "http://testserver"

        def make_request(i):
            start_time = time.time()
            response = client.post(
                "/api/agents/generate",
                headers=headers,
                json={
                    "student_id": (i % 3) + 1,
                    "course_id": 1,
                    "knowledge_point_ids": [(i % 5) + 1],
                    "resource_type": "lecture",
                    "difficulty": "easy"
                }
            )
            elapsed = time.time() - start_time
            return {
                "index": i,
                "status": response.status_code,
                "elapsed": elapsed
            }

        # 并发执行
        start = time.time()
        with ThreadPoolExecutor(max_workers=10) as executor:
            futures = [executor.submit(make_request, i) for i in range(10)]
            results = [f.result() for f in as_completed(futures)]
        total_time = time.time() - start

        # 验证结果
        assert all(r["status"] == 200 for r in results)
        assert total_time < 30  # 总时间应在 30 秒内

        print(f"\n并发测试结果:")
        print(f"  总请求数: {len(results)}")
        print(f"  总耗时: {total_time:.2f}s")
        print(f"  平均响应时间: {sum(r['elapsed'] for r in results) / len(results):.2f}s")

    @pytest.mark.parametrize("endpoint,count", [
        ("/api/resources", 100),
        ("/api/knowledge/search?q=SQL", 50),
        ("/api/statistics/platform", 20),
    ])
    def test_endpoint_throughput(self, client, auth_token, endpoint, count):
        """端点吞吐量测试"""
        headers = {"Authorization": f"Bearer {auth_token}"}

        def make_request():
            response = client.get(endpoint, headers=headers)
            return response.status_code == 200

        start = time.time()
        with ThreadPoolExecutor(max_workers=10) as executor:
            results = list(executor.map(lambda _: make_request(), range(count)))
        elapsed = time.time() - start

        success_rate = sum(results) / len(results)
        qps = len(results) / elapsed

        print(f"\n{endpoint} 吞吐量测试:")
        print(f"  请求数: {count}")
        print(f"  成功率: {success_rate * 100:.1f}%")
        print(f"  QPS: {qps:.2f}")

        assert success_rate >= 0.95  # 成功率 >= 95%
