# 智慧学工坊 EduAgent Studio —— 系统开发说明书

## 文档信息
- 项目名称：智学工坊 EduAgent Studio
- 赛题名称：基于大模型的个性化资源生成与学习多智能体系统开发
- 组类：A 组
- 出题企业：科大讯飞股份有限公司
- 版本：初稿
- 日期：2026-07-13

## 1. 需求分析
### 1.1 业务背景
高等教育学习场景中学生差异大、资源杂乱、缺少个性化辅导与闭环评估。传统教学难以满足“因材施教”。大模型与多智能体协作带来新机会。

### 1.2 用户角色
- 学生：构建画像、学习路径、资源学习、Tutor 答疑、反馈评价。
- 教师：知识库管理、生成资源、审核资源、查看学情。
- 管理员：模型配置、智能体配置、提示词管理、审计、成本、日志、治理。

### 1.3 功能需求（对应 A3）
1. 面向高等教育学习场景
2. 以具体高校课程为切入点
3. 学生画像不少于 6 个维度
4. 对话式学习画像自主构建
5. 画像随学随新、动态更新
6. 开发智能学习多智能体系统
7. 多智能体协同生成资源
8. 至少生成 5 种类型资源
9. 个性化学习路径规划和资源推送
10. 智能辅导（可选加分项）
11. 学习效果评估（可选加分项）
12. 流式输出或进度追踪
13. Markdown 渲染
14. 多模态内容卡片化展示
15. 防幻觉与内容安全过滤
16. 生成资源时绑定知识库依据
17. 至少一门完整课程知识库

### 1.4 非功能需求
- 美观大方的现代 Web 交互
- 响应时间合理，支持生成进度追踪
- 可追溯的引用来源与可信度评分
- 角色隔离、数据安全、日志可审计
- 可部署、可运行、文档完整

## 2. 总体设计
### 2.1 产品定位
EduAgent Studio 是“面向高校课程的学习智能体操作系统”，不是单一资源生成工具。

### 2.2 产品架构
- 课程知识空间：教师上传资料，自动解析、切分、知识点绑定、BM25 检索。
- 学生画像：6+ 维度的动态 Learner Memory，支持对话式构建与更新。
- 智能体编排：LangGraph StateGraph，5 个智能体协作。
- 资源工厂：6 类资源差异化渲染。
- 学习辅导 Copilot：结合画像与知识库的多模态答疑。
- 效果闭环：反馈驱动画像更新、路径调整、推荐重排。
- 治理审计：成本、调用、RAG 命中、内容安全、日志。

### 2.3 系统架构
- 前端：React 18 + Vite + TypeScript + Tailwind v4 + shadcn/ui。
- 后端：FastAPI + Pydantic + SQLAlchemy。
- 多智能体：LangGraph + LangChain Core。
- 知识库：BM25 本地检索。
- LLM：统一 Gateway（Mock/OpenAI/Qwen/DeepSeek/MiniMax）。
- 数据库：MySQL 业务表 + PostgreSQL/pgvector 预留。

### 2.4 核心数据流
教师上传课程资料 → 知识库建立
↓
学生通过对话构建画像 → Learner Memory
↓
画像 + 知识库 → 智能体编排中心
↓
生成资源并绑定证据来源 → 教师审核
↓
学生接收个性化路径和资源 → 学习与反馈
↓
画像更新 → 路径调整 → 推荐重排 → Tutor 持续辅导
↓
管理端查看审计、成本与质量数据

## 3. 模块设计
### 3.1 课程知识库
- 上传 PDF/Markdown/Word/PPT
- 自动解析、切分、BM25 索引
- 知识点绑定、证据链接、检索测试

### 3.2 学生画像
- 10 个动态画像维度
- 对话式构建界面
- 测验、反馈、Tutor 交互持续更新

### 3.3 智能体编排中心
- 5 个智能体：诊断、规划、资源生成、评估、教师审核
- SSE 流式输出、步骤状态可视化
- 结果 Markdown 渲染 + 证据来源 + 可信度

### 3.4 资源生成工厂
- 讲义、题库、代码案例、PPT 分镜、视频脚本、思维导图、复习计划、测验卡片
- ResourceRenderer 按类型差异化渲染

### 3.5 学习路径图谱
- 知识点依赖图可视化
- 节点颜色区分掌握度
- 点击薄弱点推荐资源

### 3.6 学习辅导 Copilot
- 结合画像和知识库答疑
- 多模态卡片：图文、代码、练习
- “没理解”降低难度并推荐基础资源

### 3.7 效果闭环
- 反馈后更新 mastery
- 推荐策略切换
- 学习路径动态调整

### 3.8 管理端
- 平台指标、模型配置、提示词、审计、成本、日志、治理

## 4. 数据库设计
- 课程、知识点、学生画像、掌握度、任务、资源、反馈
- 课程资料、文档切分、知识点绑定、证据链接、会话记录、智能体运行记录

## 5. 接口设计（摘要）
- 学生画像：/api/profiles/{id}/dialog
- 知识库：/api/knowledge/* 
- 智能体：/api/agents/generate 或 SSE
- 学习反馈：/api/feedbacks/submit
- Tutor：/api/tutor/chat
- 统计：/api/statistics/*

## 6. 前端设计
- 角色路由隔离：student / teacher / admin
- 关键页面：
  - 学生：StudentDashboard、StudentProfile、StudentLearningPath、ResourceLibrary、StudentTutor、LearningFeedback、LearningAnalytics
  - 教师：TeacherDashboard、TeacherKnowledgeBase、AgentWorkbench、TeacherReview、ResourceLibrary
  - 管理：AdminDashboard、AdminModelConfig、AdminAgentConfig、AdminPrompts、AdminAudit、AdminCosts、AdminLogs、AdminGovernance

## 7. 多智能体设计
- LangGraph 工作流：Diagnosis → Planning → ResourceGeneration → Assessment → TeacherReview
- 每个智能体输出结构化结果，支持工具调用与证据绑定
- 教师审核通过后发布资源，学生可学习

## 8. 测试说明
### 8.1 测试策略
- 功能测试、接口测试、UI 测试、数据闭环测试、演示场景测试

### 8.2 核心测试用例（摘要）
1. 教师上传资料后知识库可检索
2. 学生画像至少 6 维度，对话可更新
3. 多智能体生成至少 5 类资源
4. 资源绑定知识库证据
5. 学生反馈后推荐策略和路径更新
6. Tutor 答疑带引用来源

## 9. 部署说明
- 环境：Node 18+、Python 3.10+、MySQL、可选 PostgreSQL/pgvector
- 启动：`cd backend && uvicorn app.main:app --reload --port 8000`
- 启动：`cd frontend && npm install && npm run dev`
- Docker：支持 PostgreSQL + Redis + MinIO + Celery
- 初始化：数据库迁移脚本、种子数据

## 10. 创新点
1. 以课程为切入点的“学习智能体操作系统”而非单一生成工具
2. 5 智能体协作 + 证据优先生成链路
3. 10 维度动态画像 + 反馈闭环
4. 6 类资源差异化渲染 + 知识图谱学习路径
5. 管理端真实运营指标 + 成本审计
6. 教师审核 + 引用溯源 + 可信度评分

## 11. 使用说明
- 教师登录后先上传课程资料，建立知识库
- 学生登录后完善画像，查看学习路径
- 教师使用工作台生成资源并审核
- 学生使用资源库学习、Tutor 答疑、提交反馈
