## 1. 引言

### 1.1 项目背景

第十五届中国软件杯大赛 A3 赛题要求参赛团队借助大模型技术体系，融合前沿 AI 技术和工具，突破传统教育的技术与模式局限，构建高等教育个性化学习资源体系，开发智能学习智能体系统，切实满足学生的个性化、多模态学习需求。

高等教育学习场景中，学生普遍面临以下核心问题：学习资源繁杂无序，难以精准匹配自身需求；传统教学模式无法兼顾每位学生的学习节奏与特点；缺乏智能化、个性化的学习指导；学习效果缺乏持续追踪与闭环反馈。

本项目"智学工坊 EduAgent Studio"正是针对上述痛点，以高校专业课程为切入点，构建多智能体协作的个性化学习资源生成与学习闭环平台。

### 1.2 文档目的

本说明书详细阐述 EduAgent Studio 系统的需求分析、总体设计、技术架构、功能模块、数据库设计、接口设计、多智能体协作机制、知识库与防幻觉设计、安全与部署方案，旨在为系统开发、测试、部署和评审提供完整的技术参考。

### 1.3 适用范围

适用于 EduAgent Studio 系统的开发人员、测试人员、运维人员、项目管理人员以及大赛评审专家。

## 2. 系统概述

### 2.1 产品定位

EduAgent Studio 定位为**面向高校专业课程的"学习智能体操作系统"**，而非单一的资源生成工具。其核心理念是：以课程知识库为底座，以学生画像为驱动，通过多智能体协作生成个性化资源，形成"学—测—评—反馈—调整"的完整学习闭环，最终实现"因材施教"的数字化落地。

### 2.2 核心价值

- **个性化**：基于学生画像和学习行为动态调整资源推送策略
- **系统性**：覆盖从知识库建立到效果评估的完整学习链路
- **可信性**：生成资源绑定知识库证据来源，从根本上防止 AI 幻觉
- **可溯性**：所有操作全程留痕，平台运营指标实时可见

### 2.3 目标用户

| 用户角色 | 核心诉求 | 典型操作 |
|----------|----------|----------|
| 学生 | 获得适配自身水平和目标的学习资源和路径 | 构建画像、查看路径、学习资源、Tutor 答疑、提交反馈 |
| 教师 | 高效管理课程知识库、一键生成个性化资源、审核发布 | 上传资料、生成资源、审核资源、查看学情 |
| 管理员 | 保障平台稳定运行、成本可控、内容合规 | 配置模型、管理用户、审计日志、查看成本 |

### 2.4 业务边界

**包含**：学生画像构建、学习路径规划、个性化资源生成、知识库管理、Tutor 智能答疑、学习反馈闭环、管理与审计。

**不包含**：真实在线考试系统、课程选课系统、学分管理系统。

## 3. 需求分析

### 3.1 业务需求

#### 3.1.1 对话式学习画像自主构建

**需求描述**：摒弃传统繁琐表单，支持通过自然语言对话（结合学生的专业、学习目标、学习历史等）自动抽取特征，构建包含不少于 6 个维度的动态学生画像，并支持画像的随学随新。

**实现方案**：
- 学生通过前端对话界面输入自然语言描述
- 后端调用 LLM 从对话中抽取结构化画像数据
- 抽取结果以确认卡片形式展示，学生核对后一键确认
- 确认后写入 `student_profiles` 表
- 画像维度包括：知识基础、当前水平、薄弱知识点、易错点、学习目标、认知风格、资源偏好、学习时间约束、实践能力、学习动机（10 个维度）

**验收标准**：对话能保存到 `profile_dialog_messages`；抽取结果能应用到 `student_profiles`；画像至少展示 6 个维度。

#### 3.1.2 多智能体协同的资源生成

**需求描述**：系统须体现"多智能体"架构设计，通过与学生的智能交互，大模型结合 AI 前沿技术和工具，依据学生提供的专业、课程内容、知识短板、学习需求等信息，生成针对性的多模态学习资料，须由不同角色的智能体协作完成至少 5 种类型的个性化资源生成。

**实现方案**：
- 5 个智能体通过 LangGraph StateGraph 编排：诊断智能体 → 规划智能体 → 资源生成智能体 → 评估智能体 → 教师审核智能体
- 支持 6 类资源：讲义（lecture）、题库（quiz）、代码案例（code_case）、PPT 大纲（ppt）、视频脚本（video_script）、思维导图（mindmap）、复习计划（review）、测验卡片（test）
- 流式 SSE 输出，教师实时看到执行过程
- 生成结果 Markdown 渲染 + 证据来源 + 可信度评分

**验收标准**：启动生成后，执行链路逐步变绿；SSE 完成后直接展示结果；生成结果可保存到资源库。

#### 3.1.3 个性化学习路径规划和资源推送

**需求描述**：依托多智能体协同工作机制，整合系统生成的个性化资源，结合大模型对学生专业、学习进度、知识掌握情况及学习偏好的深度分析，为学生规划科学、动态的个性化学习路径，明确学习步骤和顺序；同时基于画像实现学习资源的精准推送。

**实现方案**：
- Planning Agent 生成个性化学习路径（知识点顺序 + 预估时间 + 资源类型 + 优先级）
- 学习路径图谱可视化，节点颜色区分掌握度（绿色已掌握、橙色待巩固、红色薄弱点）
- 推荐资源基于画像匹配和掌握度排序

**验收标准**：学生端能看到知识点依赖图；点击薄弱点能看到推荐资源；反馈后刷新，节点颜色能变化。

#### 3.1.4 智能辅导（加分项）

**需求描述**：当学生在学习过程中遇到问题时，系统提供即时、多模态的答疑解惑服务，通过智能体的数据分析、大模型的知识支持，结合多模态生成技术，为学生提供详细的文字解答、图解说明、短视频讲解等多样化解答形式。

**实现方案**：
- 独立 Tutor Chat 接口，结合画像和课程知识库回答
- 回答带引用来源（CitationsCard）
- "没理解"降低解释难度，推荐基础资源
- 回答中出现图解/练习/代码之一

**验收标准**：学生提问，回答带课程知识库引用；点"没理解"，系统降低解释难度并推荐基础资源。

#### 3.1.5 学习效果评估（加分项）

**需求描述**：通过实时跟踪学生的学习行为、练习测试情况、资源使用反馈等数据，依托大模型的数据分析能力实现对学生学习效果的多维度、精准评估；并根据评估结果及时动态调整学习资源推送策略和学习计划。

**实现方案**：
- Assessment Agent 分析测验结果/学习反馈
- `feedbacks.py` 触发：`UPSERT student_knowledge_mastery` → `AVG 重算 mastery_score`
- 反馈提交后推荐策略切换到基础讲义/练习题
- 学习路径中该知识点优先级提升

**验收标准**：提交低分反馈后，推荐资源切换；路径中该知识点优先级提升。

### 3.2 非功能需求

#### 3.2.1 界面与交互

系统界面美观大方、简洁明了，交互逻辑清晰，符合现代 AI 产品交互规范（如流式输出、Markdown 渲染、多模态内容卡片化展示），无明显功能与界面错误。

**实现方案**：
- React 18 + Tailwind v4 + shadcn/ui 组件库
- Markdown 渲染：`marked` 库 + `@tailwindcss/typography`
- 多模态卡片化：8 类资源差异化渲染组件（ResourceRenderer）
- 流式输出：SSE 事件驱动，实时展示智能体执行进度
- 角色隔离路由：student / teacher / admin 三套独立侧边栏

#### 3.2.2 性能要求

智能体核心功能的响应时间控制在合理范围内，保障学生的日常使用体验；多模态资源生成的响应效率需满足实际学习场景需求，提供"生成进度追踪"或"流式呈现"机制，避免长时间白屏等待。

**实现方案**：SSE 流式推送前端实时渲染；资源生成异步任务可选接入 Celery；数据库查询优化（索引、SQL 编写规范）。

#### 3.2.3 安全与合规

系统需具备完善的"防幻觉"与内容安全过滤机制，确保生成的学术内容无事实性错误、无敏感违规信息；所有 API 调用全程留痕，支持审计。

**实现方案**：BM25 检索确保生成内容基于课程知识库；证据优先生成链路（引用校验 + 可信度评分）；JWT 认证 + RBAC 权限模型；操作日志 + AI 调用记录 + 成本记录。

## 4. 总体设计

### 4.1 系统定位

EduAgent Studio 定位为 B/S 架构的 Web 应用，前端为 SPA（单页应用），后端为 REST API + SSE 服务，通过 HTTP 协议通信。

### 4.2 核心数据流

```
教师上传课程资料 → 知识库建立（解析/切分/索引/知识点绑定）
        ↓
学生通过对话构建画像 → Learner Memory（10 维度动态画像）
        ↓
画像 + 知识库 → 智能体编排中心（诊断/检索/规划/生成/审核）
        ↓
生成资源并绑定证据来源 → 教师审核 → 发布给学生
        ↓
学生接收个性化路径和资源 → 学习与反馈
        ↓
画像更新 → 路径调整 → 推荐重排 → Tutor 持续辅导
        ↓
管理端：调用审计、成本统计、内容安全
```

### 4.3 七大核心模块

| 模块 | 定位 | 状态 |
|------|------|------|
| 课程知识空间 | 教师上传资料，自动解析、切分、知识点绑定、BM25 检索 | ✅ 后端已完成 |
| 学生画像 | 10 维度动态 Learner Memory，对话式构建与更新 | ✅ 基础完成 |
| 智能体编排 | LangGraph StateGraph，5 个智能体协作，SSE 流式 | ✅ 基础完成 |
| 资源生成工厂 | 8 类资源差异化渲染，证据来源 + 可信度 | ✅ 基础完成 |
| 学习辅导 Copilot | 结合画像和知识库的多模态答疑 | ✅ 基础完成 |
| 效果闭环 | 反馈驱动画像更新、路径调整、推荐重排 | ✅ 基础完成 |
| 治理审计 | 成本、调用、RAG 命中、内容安全、日志 | ✅ 基础完成 |

## 6. 功能模块详细设计

### 6.1 登录与认证模块

**功能**：支持用户名密码登录、角色自动识别与路由跳转。

**流程**：
1. 用户输入用户名和密码
2. 后端 BCrypt 验证密码
3. 查询用户角色，生成 JWT Token
4. 前端存储 Token，自动跳转对应角色首页

**角色路由映射**：
- `admin` → `/admin`
- `teacher` → `/teacher`
- `student_member` → `/student`

### 6.2 学生画像模块

**功能**：对话式构建 10 维度动态画像。

**画像维度**：

### 6.3 智能体编排模块

**功能**：教师在工作台发起资源生成请求，5 个智能体协作完成。

**工作流节点**：
1. **Diagnosis（诊断）**：分析学生画像 + 知识点 + 学习历史，识别薄弱点
2. **Planning（规划）**：根据诊断结果生成学习路径和资源组合
3. **Generation（生成）**：从知识库检索相关 chunk，生成目标类型的资源
4. **Assessment（评估）**：检查生成质量，计算可信度评分
5. **TeacherReview（审核）**：提供质量建议，教师决定发布或驳回

**路由策略**：线性顺序执行；质量 < 7.0 时触发返工循环，最多 3 次。

**SSE 事件**：
```
event: data: {"node":"diagnosis", "step":"done", "has_diagnosis":true}
event: data: {"node":"planning", "step":"done", "has_plan":true}
event: data: {"node":"generation", "step":"done", "has_resource":true}
event: data: {"node":"done", "result":{...}}
```

### 9.1 架构概述

                        │       INIT          │
                        └─────────┬───────────┘
                                  │
                        ┌─────────▼───────────┐
                        │     SUPERVISOR      │  ← 编排路由中心
                        └─────────┬───────────┘
                                  │
              ┌───────────────────┼───────────────────┐
              │                   │                    │
     ┌────────▼────────┐  ┌──────▼──────┐   ┌────────▼────────┐
     │    DIAGNOSIS    │→│  PLANNING   │→│   GENERATION    │
     │    学习诊断       │  │  学习规划    │  │   资源生成       │

### 9.3 各智能体详细说明

#### 9.3.1 诊断智能体（Diagnosis Agent）

**核心 Prompt 模板**：
```
你是一位专业的学习分析师。你的任务是根据学生的画像和学习历史，
分析该学生在指定知识点的薄弱点。

学生画像：
{student_profile}

目标知识点：
{knowledge_points}

学习历史：
{learning_history}

请分析并输出：
1. 薄弱知识点（按优先级排序）
2. 已掌握的相关知识点
3. 学习困难原因分析
4. 推荐的学习资源类型
5. 建议的难度等级
```

**Python 实现示例**：
```python
class DiagnosisAgent:
    """诊断智能体"""
    
    def __init__(self, llm_gateway: LLMGateway):
        self.llm = llm_gateway
    
    async def analyze(
        self,
        student_profile: Dict,
        knowledge_points: List[Dict],
        learning_history: List[Dict]
    ) -> Dict:
        """执行诊断分析"""
        
        # 1. 构建 Prompt
        prompt = self._build_prompt(
            student_profile,
            knowledge_points,
            learning_history
        )
        
        # 2. 调用 LLM
        response = await self.llm.generate(
            prompt=prompt,
            temperature=0.3,  # 降低随机性，保证分析一致性
            max_tokens=2000
        )
        
        # 3. 解析结果
        diagnosis = self._parse_response(response)
        
        # 4. 补充元数据
        diagnosis.update({
            "agent": "diagnosis",
            "timestamp": datetime.now().isoformat(),
            "confidence": self._calculate_confidence(diagnosis)
        })
        
        return diagnosis
    
    def _build_prompt(self, profile, kps, history) -> str:
        return f"""学生画像：
{json.dumps(profile, ensure_ascii=False, indent=2)}

知识点列表：
{json.dumps(kps, ensure_ascii=False, indent=2)}

学习历史：
{json.dumps(history, ensure_ascii=False, indent=2)}

请分析薄弱点并返回JSON格式结果。"""
    
    def _parse_response(self, response: str) -> Dict:
        """从 LLM 响应中提取结构化结果"""
        import json
        import re
        
        # 尝试从 Markdown 代码块中提取 JSON
        match = re.search(r'```json\s*(.*?)\s*```', response, re.DOTALL)
        if match:
            return json.loads(match.group(1))
        
        # 尝试直接解析
        return json.loads(response)
```

**资源类型与 Prompt 模板映射**：

| 资源类型 | Prompt 特点 | 输出格式 |
|---------|------------|---------|
| lecture（讲义） | 详细解释 + 举例 + 引用来源 | Markdown 正文 + 引用卡片 |

**证据注入实现**：
```python
class ResourceGenerationAgent:
    """资源生成智能体"""
    
    async def generate(
        self,
        learning_plan: Dict,
        resource_type: str,
        student_profile: Dict,
        knowledge_base: KnowledgeBase
    ) -> Dict:
        """生成资源"""
        
        # 1. 检索相关知识 chunk
        kp_ids = [kp["id"] for kp in learning_plan.get("knowledge_points", [])]
        chunks = await knowledge_base.retrieve(
            knowledge_point_ids=kp_ids,
            top_k=5,
            include_metadata=True
        )
        
        # 2. 构建证据上下文
        evidence_context = self._format_evidence_context(chunks)
        
        # 3. 获取类型对应的 Prompt 模板
        prompt_template = self._get_prompt_template(resource_type)
        
        # 4. 注入证据生成资源
        prompt = prompt_template.format(
            learning_plan=learning_plan,
            student_profile=student_profile,
            evidence_context=evidence_context
        )
        
        # 5. 生成资源
        content = await self.llm.generate(prompt=prompt, temperature=0.7)
        
        # 6. 返回带证据的资源
        return {
            "content": content,
            "resource_type": resource_type,
            "evidence_chunks": [c["id"] for c in chunks],
            "citations": self._extract_citations(chunks)
        }
```

#### 9.3.4 评测智能体（Assessment Agent）

**掌握度更新规则**：
```python
class AssessmentAgent:
    """评测智能体"""
    
    MASTERY_RULES = {
        "excellent": {"threshold": 0.8, "delta": 0.15, "symbol": "↑"},
        "good": {"threshold": 0.6, "delta": 0.05, "symbol": "↑"},
        "fail": {"threshold": 0.0, "delta": -0.10, "symbol": "↓"}
    }
    
    def calculate_mastery_update(
        self,
        current_mastery: float,
        quiz_score: float
    ) -> float:
        """根据答题正确率计算掌握度更新"""
        
        if quiz_score > self.MASTERY_RULES["excellent"]["threshold"]:
            new_mastery = current_mastery + self.MASTERY_RULES["excellent"]["delta"]
        elif quiz_score > self.MASTERY_RULES["good"]["threshold"]:
            new_mastery = current_mastery + self.MASTERY_RULES["good"]["delta"]
        else:
            new_mastery = current_mastery + self.MASTERY_RULES["fail"]["delta"]
        
        # 限制在 [0, 1] 范围内
        return max(0.0, min(1.0, new_mastery))
    
    async def update_student_mastery(
        self,
        student_id: int,
        knowledge_point_id: int,
        quiz_score: float
    ) -> Dict:
        """更新学生知识点掌握度"""
        
        # 1. 获取当前掌握度
        current = await self.repo.get_mastery(student_id, knowledge_point_id)
        
        # 2. 计算新掌握度
        new_mastery = self.calculate_mastery_update(
            current.get("mastery_score", 0.5),
            quiz_score
        )
        
        # 3. UPSERT 掌握度记录
        await self.repo.upsert_mastery(
            student_id=student_id,
            kp_id=knowledge_point_id,
            mastery_score=new_mastery
        )
        
        # 4. 重算综合掌握度
        await self._recalculate_overall_mastery(student_id)
        
        return {
            "student_id": student_id,
            "kp_id": knowledge_point_id,
            "old_mastery": current.get("mastery_score", 0.5),
            "new_mastery": new_mastery,
            "change": new_mastery - current.get("mastery_score", 0.5)
        }
```

#### 9.3.5 教师审核智能体（Teacher Review Agent）

**质量评分维度**：

| 维度 | 权重 | 评估标准 |
|-----|------|---------|
| 内容准确性 | 30% | 无事实性错误，引用来源可靠 |
| 知识完整性 | 25% | 覆盖核心知识点，无明显遗漏 |
| 难度适切性 | 20% | 与目标难度匹配 |
| 格式规范性 | 15% | Markdown 格式正确，可正常渲染 |
| 证据完整性 | 10% | 引用来源完整，可追溯 |

**质量评分计算**：
```python
class TeacherReviewAgent:
    """教师审核智能体"""
    
    QUALITY_THRESHOLD = 7.0  # 质量及格线
    MAX_REVISIONS = 3       # 最大返工次数
    
    async def evaluate_quality(
        self,
        resource: Dict,
        target_difficulty: str,
        knowledge_points: List[Dict]
    ) -> Dict:
        """评估资源质量"""
        
        scores = await self._evaluate_dimensions(resource, target_difficulty, knowledge_points)
        
        # 加权计算总分
        total_score = sum(
            s["score"] * s["weight"] 
            for s in scores.values()
        )
        
        # 生成审核建议
        suggestions = self._generate_suggestions(scores, resource)
        
        return {
            "quality_score": round(total_score, 2),
            "dimension_scores": scores,
            "suggestions": suggestions,
            "risk_alerts": self._check_risk_alerts(resource),
            "needs_revision": total_score < self.QUALITY_THRESHOLD,
            "revision_count": resource.get("revision_count", 0)
        }
```

### 9.5 自动返工循环

```python
async def run_with_revision(
    self,
    initial_request: Dict,
    max_revisions: int = 3
) -> Dict:
    """带自动返工的运行循环"""
    
    resource = await self.generate_resource(initial_request)
    revision_count = 0
    
    while revision_count < max_revisions:
        # 评估质量
        review = await self.review_agent.evaluate(resource)
        
        if review["quality_score"] >= self.QUALITY_THRESHOLD:
            # 质量合格，退出循环
            resource["review"] = review
            return resource
        
        # 触发返工
        revision_count += 1
        resource["revision_count"] = revision_count
        
        # 收集返工建议
        suggestions = review.get("suggestions", [])
        
        # 根据建议重新生成
        resource = await self.revise_resource(
            resource=resource,
            suggestions=suggestions
        )
    
    # 达到最大返工次数
    resource["max_revisions_reached"] = True
    return resource
```

### 10.1 课程知识库架构

支持上传 PDF / Markdown / Word / PPT，自动识别文件类型并解析，按章节/段落切分为 chunk，每个 chunk 自动匹配课程知识点，建立关联。

**核心流程**：

2. 解析任务识别文件类型 → 切分 chunk → `course_material_chunks` 表

4. 资源生成时检索相关 chunk → 注入 prompt → 绑定证据

### 10.2 BM25 检索实现

**核心原理**：

BM25（Best Matching 25）是一种经典的信息检索算法，基于词频和文档长度对 TF-IDF 进行改进。

**参数说明**：
- `k1 = 1.5`：词频饱和度参数，控制词频对相关性评分的影响程度
- `b = 0.75`：文档长度归一化参数，控制文档长度对评分的影响程度

**Python 实现**：
```python
import re
from typing import List, Dict, Tuple
from rank_bm25 import BM25Okapi

class BM25Retriever:
    """BM25 检索器"""
    
    def __init__(self, k1: float = 1.5, b: float = 0.75):
        self.k1 = k1
        self.b = b
        self.bm25: BM25Okapi = None
        self.corpus: List[Dict] = []
    
    def build_index(self, chunks: List[Dict]) -> None:
        """
        构建 BM25 索引
        
        Args:
            chunks: chunk 列表，每个 chunk 包含 id, content, metadata
        """
        self.corpus = chunks
        
        # 中文分词（基于正则 + 停用词过滤）
        tokenized_corpus = [
            self._tokenize(chunk["content"]) 
            for chunk in chunks
        ]
        
        # 构建 BM25 索引
        self.bm25 = BM25Okapi(tokenized_corpus)
    
    def _tokenize(self, text: str) -> List[str]:
        """中文分词"""
        # 停用词列表（35个常用中文停用词）
        stopwords = {
            '的', '了', '在', '是', '我', '有', '和', '就', '不', '人',
            '都', '一', '一个', '上', '也', '很', '到', '说', '要', '去',
            '你', '会', '着', '没有', '看', '好', '自己', '这', '那', '么'
        }
        
        # 提取中文字符和英文单词
        chinese_chars = re.findall(r'[\u4e00-\u9fff]+', text)
        english_words = re.findall(r'[a-zA-Z]+', text)
        
        # 合并并过滤停用词
        tokens = []
        for chars in chinese_chars:
            tokens.extend(list(chars))  # 单字分词（简化版）
        tokens.extend([w.lower() for w in english_words])
        
        return [t for t in tokens if t not in stopwords and len(t) > 0]
    
    def search(
        self, 
        query: str, 
        top_k: int = 5
    ) -> List[Tuple[Dict, float]]:
        """
        检索相关 chunk
        
        Args:
            query: 查询文本
            top_k: 返回 top_k 条结果
        
        Returns:
            List of (chunk, score) tuples
        """
        if not self.bm25:
            raise ValueError("Index not built. Call build_index first.")
        
        # 对查询进行分词
        query_tokens = self._tokenize(query)
        
        # 计算 BM25 分数
        scores = self.bm25.get_scores(query_tokens)
        
        # 获取 top_k 索引
        top_indices = sorted(
            range(len(scores)), 
            key=lambda i: scores[i], 
            reverse=True
        )[:top_k]
        
        # 返回排序后的结果
        return [
            (self.corpus[idx], scores[idx]) 
            for idx in top_indices
        ]
    
    def get_relevance_context(
        self, 
        query: str, 
        top_k: int = 5
    ) -> str:
        """
        获取带来源标注的检索上下文
        
        Returns:
            格式化后的上下文字符串
        """
        results = self.search(query, top_k)
        
        context_parts = []
        for i, (chunk, score) in enumerate(results, 1):
            source = chunk.get("metadata", {}).get("source", "未知来源")
            page = chunk.get("metadata", {}).get("page", "N/A")
            
            part = f"""【来源{i}】{source} (页码: {page})
{chunk['content']}

---"""
            context_parts.append(part)
        
        return "\n".join(context_parts)
```

```python
class EvidenceBasedGenerator:
    """基于证据的生成器"""
    
    def __init__(
        self,
        retriever: BM25Retriever,
        llm: LLMGateway,
        citation_threshold: float = 0.5
    ):
        self.retriever = retriever
        self.llm = llm
        self.citation_threshold = citation_threshold
    
    async def generate_with_evidence(
        self,
        prompt: str,
        knowledge_point_ids: List[int],
        max_chunks: int = 5
    ) -> GenerationResult:
        """证据优先生成"""
        
        # Step 1: 检索证据
        chunks = await self._retrieve_evidence(
            knowledge_point_ids, 
            top_k=max_chunks
        )
        
        # Step 2: 验证引用
        verified_chunks = self._verify_citations(chunks)
        
        # Step 3: 格式化上下文
        evidence_context = self._format_evidence_context(verified_chunks)
        
        # Step 4: 构建增强 Prompt
        enhanced_prompt = self._build_enhanced_prompt(prompt, evidence_context)
        
        # Step 5: 调用 LLM 生成
        content = await self.llm.generate(
            prompt=enhanced_prompt,
            temperature=0.7
        )
        
        # Step 6: 提取引用并计算可信度
        citations = self._extract_citations(content)
        trustworthiness = self._calculate_trustworthiness(citations, verified_chunks)
        
        return GenerationResult(
            content=content,
            evidence_links=[c["id"] for c in verified_chunks],
            citations=citations,
            trustworthiness=trustworthiness,
            risk_level=self._get_risk_level(trustworthiness)
        )
    
    def _build_enhanced_prompt(self, base_prompt: str, evidence_context: str) -> str:
        """构建带证据的增强 Prompt"""
        
        return f"""你是一个严谨的教育内容生成专家。

【重要指令】
1. 所有生成内容必须基于以下证据来源，不得编造任何信息
2. 在适当位置使用 [来源1], [来源2] 等格式标注引用来源
3. 如果某知识点在证据中找不到，不要生成该内容，明确标注"此内容无可靠来源"
4. 保持学术严谨性，避免夸大或绝对化表述

【证据来源】
{evidence_context}

【生成任务】
{base_prompt}

请基于上述证据来源生成内容。"""
    
    def _calculate_trustworthiness(
        self, 
        citations: List[str], 
        chunks: List[Dict]
    ) -> float:
        """
        计算可信度评分
        
        评分公式：
        trustworthiness = citation_rate * evidence_quality * consistency_check
        
        - citation_rate: 引用覆盖率（引用chunk数/总chunk数）
        - evidence_quality: 证据质量（chunk相关性平均分）
        - consistency_check: 一致性检查（是否有冲突内容）
        """
        
        if not chunks:
            return 0.0
        
        # 引用覆盖率
        cited_ids = set(citations)
        total_chunks = len(chunks)
        citation_rate = len(cited_ids & {c["id"] for c in chunks}) / total_chunks
        
        # 证据质量（基于 BM25 分数归一化）
        avg_relevance = sum(
            c.get("relevance_score", 0.5) for c in chunks
        ) / total_chunks
        evidence_quality = min(1.0, avg_relevance)
        
        # 一致性因子（简化版，假设无冲突）
        consistency_check = 0.95
        
        return round(citation_rate * evidence_quality * consistency_check, 2)
```

### 10.4 可信度评分

| 评分区间 | 风险等级 | 颜色标识 | 处理方式 | 触发动作 |
|----------|----------|----------|----------|----------|
| >= 0.8 | ✅ 低风险 | 绿色 | 直接使用 | 正常发布 |
| 0.5-0.8 | ⚠️ 中风险 | 黄色 | 建议复核 | 发送审核通知 |
| 0.3-0.5 | 🔴 高风险 | 橙色 | 教师复核 | 强制审核 + 标记 |
| < 0.3 | ⛔ 严重 | 红色 | 需大改重写 | 拒绝发布 + 返工 |
