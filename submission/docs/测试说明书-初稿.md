智学工坊 EduAgent Studio —— 测试说明书（软件杯初稿）

## 1. 测试目标
验证系统是否满足 A3 赛题功能、非功能、文档与交付要求，并确保演示可复现。

## 2. 测试范围
- 教师端知识库建立
- 学生端画像构建与学习路径
- 智能体资源生成与审核
- 学生反馈闭环
- Tutor 智能辅导
- 管理端指标与审计
- 非功能：响应时间、Markdown 渲染、卡片化展示、角色隔离

## 3. 测试环境
- 操作系统：Windows 10/11
- 前端：Node 18+
- 后端：Python 3.10+
- 数据库：MySQL
- 可选：PostgreSQL + pgvector、Redis、MinIO、Celery

## 4. 测试策略
- 手工功能测试
- 接口测试
- 界面截图验证
- 数据闭环测试
- 演示流程测试
