# EduAgent Studio 参赛演示脚本

> 建议成片：6 分 30 秒，不超过 7 分钟
>
> 演示基线：V2.1，2026-07-17
>
> 主案例：CS301《数据库系统原理》“事务与 ACID”

## 1. 演示目标

用一条真实业务链路证明：

```text
课程知识库
  → 学生画像与掌握度
  → 多智能体诊断/规划/生成/评测/审核建议
  → 真实课程 chunk 引用
  → 教师审核
  → 学生 Tutor/路径/任务/资源
  → 学习反馈更新掌握度与推荐
  → 管理员查看模型、成本、安全与审计
```

成片不依赖 PPT 模拟页面，所有交互均来自当前运行的 Web 系统。

## 4. 6 分 30 秒分镜

### 00:00–00:20 问题与方案

**画面**：登录页与产品名称。

**解说**：

> 智学工坊 EduAgent Studio 面向高校课程，将学生画像、课程知识库、多智能体资源生成、教师审核和学习反馈组成可追溯闭环。我们用“事务与 ACID”展示一次真实使用。

**验收点**：项目名称、赛题定位、真实 Web 入口。

### 00:20–01:05 教师检查课程知识库

**操作**：

1. 使用 `teacher_li` 登录。
2. 进入“课程知识库”，选择 CS301。
3. 展示课程材料已解析、分块数和版本。
4. 搜索“事务与 ACID”，打开命中的课程章节。
5. 展示 chunk ID、标题、原文和已确认知识点关联。

**解说**：

> 课程材料不是一段隐藏 Prompt。系统将文档解析成带来源位置的 MySQL 分块，教师确认分块与知识点的关系，后续生成使用真实整数 chunk ID 引用。

**验收点**：真实数据、中文检索、教师知识点确认。

### 01:05–02:40 多智能体生成资源

**操作**：

1. 进入“智能体工作台”。
2. 选择 `student_zhang`、“事务与 ACID”、标准难度和“分层练习题”。
3. 填写目标：“区分 ACID 四个特性，并能用银行转账案例解释失败回滚”。
4. 启动生成，让画面完整显示诊断、规划、资源生成、评测、审核建议和可选修订轨迹。
5. 打开结果，展示个性化目标、题目/答案、质量分数、可信等级和引用。
6. 展开证据，核对 `[引用:chunk_id]` 与原文。
7. 保存草稿并提交审核。

**解说**：

> 教师不是只输入一句 Prompt。Diagnosis Agent 读取画像与掌握度，Planning Agent 规划内容，Generation Agent 优先读取课程证据，Assessment 和 Teacher Review Agent 检查质量。质量分低于 7 时最多返工 3 次。没有有效引用时结果会降级为草稿，不伪造高可信结论。

**验收点**：学生画像输入、LangGraph 节点、SSE、修订循环、课程引用、SQLite checkpoint。

### 02:40–03:15 教师审核与发布边界

**操作**：

1. 进入“教师审核”。
2. 打开刚提交的 `pending_review` 资源。
3. 查看内容、证据和智能体建议，填写审核评语。
4. 验证证据后选择“通过”，状态变为 `approved`。

**解说**：

> Teacher Review Agent 只提供建议，不代替教师。资源只有通过人工审核后才会进入学生资源库和推荐。

**验收点**：状态机、审核记录、高风险标记拦截、人在回路。

### 03:15–04:05 学生画像与学习路径

**操作**：

1. 登出教师，使用 `student_zhang` 登录。
2. 进入“学习画像”，展示目标、知识基础、认知风格、偏好、时间约束和掌握度。
3. 在对话中输入：“我每周可以学 4 小时，更喜欢用真实案例理解事务，目标是能排查并发异常。”
4. 检查抽取的 `weekly_hours`、`cognitive_style`、`learning_goal`，点击确认应用。
5. 进入“学习路径”，展示事务节点的掌握度、前置边和当前学习点。

**解说**：

> 画像抽取结果不会自动覆盖学生数据，必须由学生确认。系统存储更新前后快照，学习路径从当前知识层级和掌握度实时构建。

**验收点**：12 维画像、对话抽取、学生确认、前后快照、动态路径。

### 04:05–05:05 Tutor 对话式主入口

**操作**：

1. 进入 Tutor 主页。
2. 输入：“用银行转账案例解释原子性和隔离性的区别，然后给我 2 道判断题。”
3. 展示 Supervisor 的课程检索、讲解/题库工具进度。
4. 展示 Markdown 回答、课程引用、题目内容块和执行耗时。
5. 对回答点击有用/无用反馈。

**解说**：

> Tutor 是学生主入口，同时保留画像、路径、任务和资源专业页。Supervisor 先注入画像和课程证据，再在检索、讲解、练习、代码、思维导图、PPT、图像和语音工具中选择。

**验收点**：对话主入口、课程 RAG、tool calling/降级路由、结构化内容块。

### 05:05–05:45 学习资源与反馈闭环

**操作**：

1. 进入“学习资源”，找到刚审核通过的资源。
2. 展示个性化标签、可信等级与证据详情。
3. 进入“学习反馈”，对该资源提交 `quiz_result = 0.75` 和一句学习记录。
4. 展示事务知识点掌握度更新前/后、路径调整与下一步资源。

**解说**：

> 学生反馈不只是一条评论。测验或自评可更新资源目标知识点的掌握度，再即时重新计算综合掌握度、路径和推荐。

**验收点**：只显示 approved 资源、反馈落库、掌握度更新、推荐调整。

### 05:45–06:20 管理员治理与审计

**操作**：

1. 登出学生，使用 `admin` 登录。
2. 快速展示“模型配置”中的 Provider、Model 和密钥“已配置”状态，不回显明文。
3. 进入“调用审计”，筛选刚才的调用，展示模型、状态、Token、耗时和成本。
4. 进入“安全治理”，展示引用覆盖率、内容安全、小时调用上限和月度预算。
5. 展示操作/登录日志中对应记录。

**解说**：

> 平台统一管理模型、Prompt、成本和安全策略。API Key 加密入库且不回显明文，LLM Gateway 在调用前后扫描输入、输出和工具参数，同时记录 Token、成本和失败原因。

**验收点**：加密凭证、调用记录、成本、内容安全、操作审计。

### 06:20–06:30 收束

**画面**：管理驾驶舱或三角色页面快速蒙版。

**解说**：

> EduAgent Studio 的价值不是单次生成内容，而是让课程证据、学生状态、多智能体协作、教师决策和学习效果持续闭环。

## 5. 拍摄规范

### 5.1 画面

- 1920 × 1080，30 fps，浏览器缩放 100%。
- 鼠标移动要慢，点击前停留 0.3–0.5 秒，不在长表格中快速抖动滚动条。
- 对长时生成段落允许加速，但节点顺序和最终结果必须连续，不通过剪辑伪造成功。
- 不展示终端中的 `.env`、数据库密码、API Key、本地路径或个人隐私。

### 5.2 解说与字幕

- 每个镜头只讲一个产品价值，不逐字朗读页面。
- 字幕使用简体中文，专有名词保持 `LangGraph`、`SSE`、`RAG`、`chunk ID`。
- 不宣称尚未用真实凭证验证的外部能力。
- 不宣称“完全消除幻觉”，统一表述为“证据优先、引用校验、风险降级和教师审核”。

## 6. 故障处理

| 故障 | 处理 |
| --- | --- |
| 多智能体节点失败 | 保留当前画面作内部调试，不将该次结果剪成正式成片；根据 `run_id` 查看 checkpoint 和调用日志。
| SSE 中断 | 刷新后通过工作流状态查询已完成节点，不重复保存未确认资源。
| 生成无引用 | 保留 `draft` 结果解释降级逻辑，若影响主案例，检查课程种子和知识点关联后重录。
| 讯飞失败 | 不切换假结果。只有真实重试成功才保留该片段，否则从成片删除外部能力宣称。
| 画像抽取不准确 | 展示学生不确认或修改输入，不将错误候选写入画像。
| 审核拒绝 | 这是正常产品行为；记录理由，资源回到 `rejected`，修改后重新提交。

- [ ] 三类角色切换清晰，学生没有看到草稿/待审资源。
- [ ] 视频中无密码、API Key、JWT、数据库口令、真实学生隐私或本地私有路径。
- [ ] 字幕、解说、PPT 和代码基线的技术栈、测试数和功能状态一致。
- [ ] 视频能够在无声情况下依靠字幕理解，音频清晰且无长时间空白。
- [ ] 录制中创建的临时资源和反馈已按交付要求保留或清理，不留重复测试数据。
