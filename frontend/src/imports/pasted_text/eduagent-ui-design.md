请不要把它设计成普通后台管理系统，也不要设计成普通聊天机器人。它应该像一个成熟的 AI 教育 SaaS 平台，兼具“学习平台”“智能体工作台”“课程资源生成平台”“教学分析驾驶舱”的产品感。

# 五、组件与技术映射说明

该项目实际前端使用 Vue3 + Element Plus + ECharts + marked。请设计时尽量使用能被这些技术自然实现的组件。

设计稿中的组件可以对应：

* Button → Element Plus Button
* Input → Element Plus Input
* Select → Element Plus Select
* Table → Element Plus Table
* Tabs → Element Plus Tabs
* Tag → Element Plus Tag
* Progress → Element Plus Progress
* Dialog / Drawer → Element Plus Dialog / Drawer
* Timeline / Steps → Element Plus Timeline / Steps
* Card → 自定义卡片 + Element Plus Card
* Charts → ECharts
* Markdown 正文 → marked 渲染区域

不要设计过于复杂、难以实现的 3D 元素和大型动画。可以使用轻量渐变、阴影、发光节点、线性图标、卡片动效。
