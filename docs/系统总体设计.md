# 系统总体设计

## 一、项目概述

**项目名称**：智学工坊 EduAgent Studio
**英文名**：EduAgent Studio
**参赛赛题**：中国软件杯 A3 — 基于大模型的个性化资源生成与学习多智能体系统开发
**参赛赛道**：A 组（本科）

**项目定位**：面向高校课程学习场景，基于学生画像和知识点掌握情况，组织多个学习智能体协同完成学习诊断、路径规划、资源生成、评测反馈和学习分析，形成「画像 - 生成 - 学习 - 评测 - 优化」的个性化学习闭环。

## 二、核心业务流程

```
┌──────────────┐    ┌──────────────┐    ┌──────────────┐
│  学生画像     │───▶│  学习诊断     │───▶│  资源规划     │
│  建立与维护   │    │  智能体      │    │  智能体      │
└──────────────┘    └──────────────┘    └──────────────┘
       ▲                                         │
       │                                         ▼
┌──────────────┐    ┌──────────────┐    ┌──────────────┐
│  学习反馈     │◀───│  教师审核     │◀───│  资源生成    │
│  提交与更新   │    │  中心        │    │  智能体      │
└──────────────┘    └──────────────┘    └──────────────┘
       │                                         │
       │                                         ▼
       │              ┌──────────────┐    ┌──────────────┐
       └─────────────▶│  评测反馈     │◀───│  资源库      │
                      │  智能体      │    │  管理        │
                      └──────────────┘    └──────────────┘
```

### 详细流程

1. **教师创建课程**：教师在课程空间创建课程，添加知识点，设置学习目标
2. **学生画像建立**：系统根据学生基本信息和初始测试结果建立学生画像
3. **发布学习任务**：教师发布学习任务，指定目标知识点
4. **智能体协作链路**：
   - 学习诊断智能体分析学生薄弱点
   - 资源规划智能体生成学习路径
   - 资源生成智能体生成个性化学习资源
   - 教师审核资源质量
   - 学生学习与测验反馈
   - 评测反馈智能体生成反馈并更新画像
5. **分析看板**：展示掌握度、薄弱点、资源分布等分析报表

## 三、系统功能模块

### 3.1 学生画像模块

- 画像建立：收集学生基本信息、学习目标、兴趣方向、资源偏好
- 画像详情：展示薄弱知识点、优势知识点、历史任务、测验记录
- 画像更新：根据学习反馈和测验结果自动更新掌握度

### 3.2 课程空间模块

- 课程管理：创建、编辑、归档课程
- 知识点管理：添加、编辑课程知识点，设置难度等级
- 学习任务：发布学习任务，指定目标知识点和截止时间

### 3.3 智能体工作台模块

- 配置区：选择学生、课程、知识点、资源类型、难度
- 执行链路：可视化展示5个智能体的执行状态
- 结果展示：诊断结果、学习路径、生成资源、评测反馈、审核建议

### 3.4 学习资源模块

- 资源列表：按课程、类型、状态筛选学习资源
- 资源详情：展示资源正文、关联知识点、生成元数据
- 资源审核：教师审核学习资源，支持通过/拒绝/需修订
- 资源导出：支持导出 Markdown 格式

### 3.5 学习反馈模块

- 反馈提交：支持自评反馈、测验结果、学习笔记、问题反馈
- 掌握度评估：Slider 评分，0-100%
- 画像联动：提交后自动触发画像更新

### 3.6 学习分析看板模块

- 掌握度分布：直方图展示学生掌握度分层
- 薄弱知识点：横向条形图 TOP 10
- 资源类型分布：饼图展示各类型资源占比
- 调用趋势：折线图展示近14天智能体调用趋势
- 审核通过率：横向条形图按课程展示
- Token消耗分布：南丁格尔玫瑰图按智能体分类

### 3.7 异步任务模块

- Embedding 计算：批量计算知识点/资源 embedding
- 资源生成：长文本资源异步生成
- 批量题库生成：按知识点批量生成习题
- 每日定时任务：成本汇总、缓存清理、学习效果分析

## 五、多智能体设计

### 5.1 智能体职责

| 智能体 | 职责 | 输入 | 输出 |
|--------|------|------|------|
| 学习诊断 | 分析薄弱知识点 | 学生画像、知识点、历史反馈 | 薄弱点列表、学习难点、资源需求 |
| 资源规划 | 生成学习路径 | 诊断结果、学习目标 | 学习路径、资源组合方案 |
| 资源生成 | 生成具体资源 | 学习路径、资源类型 | 学习资源正文 |
| 评测反馈 | 分析学习效果 | 测验结果、反馈 | 掌握度更新、改进建议 |
| 教师审核辅助 | 质量检查 | 生成资源、难度要求 | 质量评分、检查项、修改建议 |

### 5.2 工作流状态机

```
State: {

  resource_type, difficulty,
  student_profile, diagnosis, learning_plan,
  generated_resource, assessment,
  teacher_review_suggestion,
  current_step, messages, error
}
```

## 六、安全设计

- **认证**：JWT Bearer Token，HS256 签名，24小时有效期
- **权限**：RBAC 角色模型（admin / teacher / student_member）
- **密钥**：API Key AES-GCM 加密存储
- **密码**：BCrypt 哈希
- **日志**：全链路操作日志追踪
