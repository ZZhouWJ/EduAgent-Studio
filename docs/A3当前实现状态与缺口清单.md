## 3. 加分项

### 3.1 智能辅导

已实现学生主入口式 Tutor，具备：

- 课程上下文和学生画像注入。
- Supervisor 多轮工具选择与执行轨迹。
- 文字讲解、练习、代码、思维导图、PPT、图像和语音内容块。
- 图片上传理解、课程证据引用和可用性反馈。
- 模型不遵循内容块嵌入语法时，未引用卡片在回答末尾保底展示。

### 3.2 学习效果评估

已实现「任务进度/测验/自评/疑问 -> 学习反馈 -> 知识点掌握度 -> 画像和路径 -> 推荐重排 -> 分析看板」数据闭环。学生不能更新他人任务或读取他人画像，教师只能访问所属课程。

## 6. 验收顺序

1. 用教师账号上传或检查 CS301 课程材料，在知识库中确认知识点关联。
2. 在多智能体工作台选择学生、知识点和资源类型，观察五阶段 SSE 进度。
3. 检查生成资源的引用、可信等级和审核建议，保存草稿并进入教师审核。
4. 用学生账号在 Tutor 中完成一次带课程引用和多模态内容块的答疑。
5. 完成任务、提交测验/自评反馈，对比画像、学习路径、资源推荐和分析看板的变化。
6. 用管理员账号检查模型调用、成本、审计、治理阈值和内容安全开关。
