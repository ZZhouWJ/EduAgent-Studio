## 二、部分完成模块

### 2.1 学生画像 — 数据缺失
**状态**：页面和 API 已实现，但数据库缺少种子数据。

- `student_profiles` 表：`10_insert_a3_initial_data.sql` 中 **未插入任何学生画像数据**
- `student_knowledge_mastery` 表：**未插入任何掌握度数据**
- 演示脚本中提到的李明、王悦、陈思雨的画像在数据库中不存在
- 这导致：学生画像列表为空、智能体工作台学生下拉为空、学习分析看板 A3 接口无数据

### 2.2 学习分析看板 — A3 接口部分为 mock
**状态**：6 个图表页面已实现，调用了 A3 统计 API。

- `statistics_service.py` 中的 A3 学习分析函数（learning_overview / mastery_distribution 等）**全部返回 hardcoded mock 数据**
- `statistics_learning_repo.py` 存在但方法未调用
- 前端已正确对接 A3 接口（新增 7 个函数），但后端未真实查询数据库

### 2.3 学习反馈 → 画像更新链路断裂
**状态**：反馈提交页面和 API 已实现，但提交后**不会自动更新画像和掌握度**。

- `feedbacks.py` 的 `submit_feedback` 只做了 INSERT，没有触发：
  - 知识点掌握度更新（`student_knowledge_mastery` 表）
  - 画像综合掌握度重算（`student_profiles.mastery_score`）
  - 薄弱点重新计算
- 反馈闭环的核心功能未完成

### 2.4 防幻觉机制 — 仅有架构文档
**状态**：`docs/` 中有设计文档，但 `backend/app/rag/` 目录**不存在**。

- 证据锁定式 RAG 机制没有代码实现
- 资源生成智能体生成时**不查询课程知识库**
- 没有文档加载 / 切分 / Embedding / 向量检索代码
- 没有证据来源绑定和可信度评分
- `pgvector/` 目录有 SQL Demo 但没有 Python 检索代码
