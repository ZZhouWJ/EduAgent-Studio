# 提示词模板体系说明

> 文档版本：v1.0
> 更新日期：2026-06-03
> 适用系统：AI-Collab-Audit-System

---

## 1. 概述

提示词模板（Prompt Template）是 AI-Collab-Audit-System 的核心功能之一，旨在为高校项目协作场景提供高质量、可复用的 AI 任务生成指令。用户可在发起 AI 生成时选择合适的模板，系统将模板中的 `{{变量占位符}}` 替换为实际业务数据后，发送给 AI 模型进行内容生成。

**模板与版本机制**：每个模板支持多版本管理（`prompt_versions` 表），用户可以创建新版本、切换当前激活版本、查看历史版本。模板默认启用（`is_active = 1`）。

## 4. 变量占位符规范

所有模板的 `prompt_content` 中使用统一的 `{{变量名}}` 格式作为运行时替换占位符。前端 AI 生成流程在调用模板时，将这些占位符替换为用户的实际业务数据。

**通用占位符**（所有模板均可用）：

| 变量名 | 说明 |
|-------|------|
| `{{project_name}}` | 项目名称 |
| `{{additional_context}}` | 补充上下文说明 |
| `{{user_name}}` | 当前用户名 |
| `{{task_title}}` | 任务标题 |

**模板专用占位符**（按模板不同而不同），示例：

| 模板 | 专用占位符 |
|------|----------|
| 项目需求分析生成 | `{{project_background}}`, `{{project_goals}}`, `{{target_users}}`, `{{constraints}}` |
| 敏捷用户故事生成 | `{{sprint_duration}}`, `{{team_size}}`, `{{feature_list}}`, `{{sprint_assignments}}` |
| 毕业设计开题报告 | `{{student_name}}`, `{{thesis_title}}`, `{{literature_review}}`, `{{research_methods}}` |
| MySQL DDL 生成 | `{{db_name}}`, `{{entity_design}}` |
| AI 代码质量审核 | `{{ai_model_name}}`, `{{programming_language}}`, `{{ai_generated_code}}` |
| 文献综述章节生成 | `{{research_topic}}`, `{{min_citations}}`, `{{existing_literature}}` |
| 实验报告摘要 | `{{experiment_name}}`, `{{experiment_type}}`, `{{experiment_data}}` |

## 5. 模板来源与开源合规

### 5.1 自主设计原则

本系统的所有提示词模板均为**自主设计改写**，未整段复制任何第三方仓库的原文。所有模板内容基于以下业务场景重新编写：

- 高校计算机/软件类课程报告规范
- 数据库课程设计（MySQL 8.0）的技术栈要求
- 敏捷软件工程（Scrum）的实践标准
- GB/T 7714-2015 学术论文格式规范
- OpenAPI 3.0 国际标准接口规范
- pytest 官方测试框架最佳实践

### 5.2 参考来源

少量模板的**设计思路**参考了以下开源项目的分类方式和结构，属于公开知识：

| 参考项目 | 许可证 | 参考内容 | 说明 |
|---------|--------|---------|------|
| [dair-ai/Prompt-Engineering-Guide](https://github.com/dair-ai/Prompt-Engineering-Guide) | MIT | 提示词评审维度框架 | Prompt Engineer 评审维度（Role/Task/Context/Constraints/Examples） |
| [yaojingang/yao-open-prompts](https://github.com/yaojingang/yao-open-prompts) | MIT | 模板分类体系 | 项目管理和文档生成分类结构 |

上述两个项目均采用 MIT 许可证，允许自由使用和改写。本系统的模板**不包含**其原文内容，仅参考其分类框架。

### 5.3 合规声明

- 本系统的提示词模板不包含任何受版权保护的文学作品原文。
- 所有模板的 `prompt_content` 均为针对高校项目协作场景的**功能性指令**，不受著作权保护。
- 模板中引用的格式规范（如 GB/T 7714-2015、OpenAPI 3.0）是**公开技术标准**，不受版权限制。

## 6. 模板管理

### 6.1 前端管理入口

管理员和教师可通过系统前端 `/prompts` 页面管理提示词模板：

- **查看模板列表**：按任务类型筛选，支持关键词搜索
- **查看模板详情**：查看当前版本内容、历史版本列表
- **创建新模板**：填写基本信息，创建第一版内容
- **创建新版本**：对已有模板追加新版本（输入新内容）
- **激活版本**：将某历史版本设为当前活跃版本
- **禁用/启用模板**：通过 `is_active` 开关控制模板是否可见

### 6.2 数据库存储结构

```
prompt_templates          prompt_versions
+-------------------+     +----------------------+
| template_id (PK)  |     | prompt_version_id (PK)|
| template_name     |◄────| template_id (FK)      |
| task_type_id (FK) |     | version_no (INT)      |
| description       |     | prompt_content (TEXT)  |
| current_version_id|◄────| prompt_version_id (PK)|
| is_active         |     | change_note           |
+-------------------+     +----------------------+
```

## 7. 模板初始化数据

### 7.1 执行方式

由于 MySQL 8.x 在 Windows 环境下通过 `mysql.exe` CLI 导入 UTF-8 多行内容时存在编码问题，请使用 Python 执行导入：

```bash
cd database
python import_prompts.py
```

依赖：`pip install pymysql`

### 7.2 幂等性

`import_prompts.py` 内含幂等逻辑（DELETE 旧数据后重新 INSERT），可重复执行以同步最新模板。

### 7.3 初始化状态

- 24 个模板全部创建完成（ID 31-54）
- 每个模板含 1 个初始版本（v1）
- 所有模板 `is_active = 1`（已启用）
- `created_by = 1`（admin 用户）
