# 课程知识库与防幻觉机制

> 本文档描述 EduAgent Studio 的课程知识库架构、RAG 检索流程以及防幻觉机制设计。

## 一、项目背景

EduAgent Studio（智学工坊）面向高校课程学习场景，为解决大模型生成学习资源时可能出现的**幻觉（Hallucination）**问题——即生成内容与课程事实不符、知识引用错误、难度偏离大纲等问题——系统设计了完整的**课程知识库 + RAG 检索 + 防幻觉机制**体系。

**核心目标**：
1. 确保生成内容严格基于课程知识库中的真实文档片段
2. 对每段生成内容提供可溯源的引用标注
3. 对低可信度内容给出明确风险提示，触发教师复核

#### 2.3.1 文档加载器（document_loader）

负责从多种格式的课程文档中提取文本内容。

```python
# backend/app/rag/document_loader.py
from abc import ABC, abstractmethod
from pathlib import Path
from typing import List

class BaseDocumentLoader(ABC):
    """文档加载器基类"""
    
    @abstractmethod
    def load(self, file_path: str) -> str:
        """加载单个文档，返回纯文本内容"""
        pass

class MarkdownLoader(BaseDocumentLoader):
    """Markdown 文档加载器"""
    
    def load(self, file_path: str) -> str:
        with open(file_path, "r", encoding="utf-8") as f:
            return f.read()

class PDFLoader(BaseDocumentLoader):
    """PDF 文档加载器（使用 PyPDF2 或 pdfplumber）"""
    
    def load(self, file_path: str) -> str:
        import pdfplumber
        text_parts = []
        with pdfplumber.open(file_path) as pdf:
            for page in pdf.pages:
                text = page.extract_text()
                if text:
                    text_parts.append(text)
        return "\n".join(text_parts)

class HTMLLoader(BaseDocumentLoader):
    """HTML 文档加载器"""
    
    def load(self, file_path: str) -> str:
        from bs4 import BeautifulSoup
        with open(file_path, "r", encoding="utf-8") as f:
            soup = BeautifulSoup(f, "html.parser")
        return soup.get_text(separator="\n", strip=True)

class DocumentLoaderFactory:
    """文档加载器工厂"""
    
    LOADERS = {
        ".md": MarkdownLoader,
        ".markdown": MarkdownLoader,
        ".pdf": PDFLoader,
        ".html": HTMLLoader,
        ".htm": HTMLLoader,
    }
    
    def load(self, file_path: str) -> str:
        ext = Path(file_path).suffix.lower()
        loader_class = self.LOADERS.get(ext, MarkdownLoader)
        return loader_class().load(file_path)
    
    def load_batch(self, file_paths: List[str]) -> List[str]:
        """批量加载多个文档"""
        return [self.load(fp) for fp in file_paths]
```

#### 2.3.2 文本切分器（text_splitter）

将长文档切分为适合嵌入和检索的文本块（Chunk）。

```python
# backend/app/rag/text_splitter.py
from typing import List, Tuple

class TextSplitter:
    """
    文本切分器
    使用 RecursiveCharacterTextSplitter 策略
    """
    
    def __init__(
        self,
        chunk_size: int = 500,
        overlap: int = 50,
        separators: List[str] = None
    ):
        """
        Args:
            chunk_size: 每个文本块的字符数（建议 300-1000）
            overlap: 相邻块之间的重叠字符数（建议 chunk_size 的 10-20%）
            separators: 分隔符优先级列表
        """
        self.chunk_size = chunk_size
        self.overlap = overlap
        self.separators = separators or [
            "\n\n",   # 优先按段落分割
            "\n",     # 其次按行分割
            "。",     # 中文句号
            "！",     # 中文感叹号
            "？",     # 中文问号
            "；",     # 中文分号
            "，",     # 中文逗号
            " ",      # 英文空格
            "",       # 最后按字符分割
        ]
    
    def split_text(self, text: str, source_name: str = "") -> List[dict]:
        """
        切分文本为多个 chunk，每个 chunk 携带元数据
        
        Returns:
            List[dict], 每个元素包含:
            - content: 文本内容
            - chunk_index: 块序号
            - source: 来源文件名
        """
        chunks = []
        start = 0
        chunk_index = 0
        
        while start < len(text):
            end = start + self.chunk_size
            chunk = text[start:end]
            
            # 尝试在最佳分隔符处截断，保持语义完整
            if end < len(text):
                chunk = self._split_at_separator(chunk, text[end])
            
            chunks.append({
                "content": chunk.strip(),
                "chunk_index": chunk_index,
                "source": source_name,
                "char_start": start,
                "char_end": start + len(chunk),
            })
            
            start = start + self.chunk_size - self.overlap
            chunk_index += 1
        
        return chunks
    
    def _split_at_separator(self, chunk: str, next_char: str) -> str:
        """在最佳分隔符处截断 chunk"""
        for sep in self.separators:
            if sep and sep in chunk:
                last_sep_idx = chunk.rfind(sep)
                if last_sep_idx > self.chunk_size * 0.5:  # 至少保留50%的chunk
                    return chunk[:last_sep_idx]
        return chunk
    
    def split_documents(self, documents: List[dict]) -> List[dict]:
        """
        批量切分文档列表
        
        Args:
            documents: [{"content": "...", "source": "..."}, ...]
        
        Returns:
            展平的 chunk 列表
        """
        all_chunks = []
        for doc in documents:
            chunks = self.split_text(doc["content"], doc.get("source", ""))
            all_chunks.extend(chunks)
        return all_chunks
```

**切分策略说明**：
- `chunk_size=500`：每个块约 250-300 个中文字符，适合精确保留语义单元
- `overlap=50`：相邻块重叠 50 字符，避免知识点被硬切断导致语义丢失
- 分隔符优先级：段落 → 句子 → 字符，优先保证语义完整性

#### 2.3.3 Embedding 服务（embedding_service）

将文本块转换为高维向量表示，支持多种 Embedding 模型。

```python
# backend/app/rag/embedding_service.py
from abc import ABC, abstractmethod
from typing import List
import httpx

class BaseEmbeddingService(ABC):
    """Embedding 服务基类"""
    
    @property
    @abstractmethod
    def dimension(self) -> int:
        """返回向量维度"""
        pass
    
    @abstractmethod
    async def embed(self, texts: List[str]) -> List[List[float]]:
        """将文本列表转换为 embedding 向量列表"""
        pass

class OpenAIEmbedding(BaseEmbeddingService):
    """OpenAI text-embedding-ada-002 / text-embedding-3-small"""
    
    def __init__(self, api_key: str, model: str = "text-embedding-3-small"):
        self.api_key = api_key
        self.model = model
        self.dimension_value = 1536 if "3" in model else 1536
    
    @property
    def dimension(self) -> int:
        return self.dimension_value
    
    async def embed(self, texts: List[str]) -> List[List[float]]:
        async with httpx.AsyncClient() as client:
            response = await client.post(
                "https://api.openai.com/v1/embeddings",
                headers={
                    "Authorization": f"Bearer {self.api_key}",
                    "Content-Type": "application/json",
                },
                json={
                    "input": texts,
                    "model": self.model,
                    "dimensions": self.dimension_value,
                },
                timeout=60.0,
            )
            response.raise_for_status()
            result = response.json()
            return [item["embedding"] for item in result["data"]]

class BGEEmbedding(BaseEmbeddingService):
    """BAAI/bge-* 系列本地或远程部署的 Embedding 模型"""
    
    def __init__(self, base_url: str, model_name: str = "bge-m3"):
        self.base_url = base_url.rstrip("/")
        self.model_name = model_name
        self.dimension_value = self._get_dimension()
    
    def _get_dimension(self) -> int:
        # BGE-M3 维度为 1024，BGE-Large 为 1024，BGE-Small 为 512
        return 1024
    
    @property
    def dimension(self) -> int:
        return self.dimension_value
    
    async def embed(self, texts: List[str]) -> List[List[float]]:
        async with httpx.AsyncClient() as client:
            response = await client.post(
                f"{self.base_url}/embed",
                json={"inputs": texts, "model": self.model_name},
                timeout=60.0,
            )
            response.raise_for_status()
            result = response.json()
            return result["embeddings"]
```

#### 2.3.4 向量存储（vector_store）

使用 PostgreSQL + pgvector 存储和检索向量数据。

**数据库 Schema**：

```sql
-- backend/database/pgvector/01_enable_pgvector.sql
CREATE EXTENSION IF NOT EXISTS vector;

-- backend/database/pgvector/02_create_embeddings_table.sql
CREATE TABLE IF NOT EXISTS knowledge_point_embeddings (
    embedding_id SERIAL PRIMARY KEY,
    kp_id        INTEGER NOT NULL,          -- 关联知识点 ID
    content_chunk TEXT NOT NULL,             -- 文本内容
    embedding    VECTOR(768),                -- 768维向量（BGE-M3 或其他模型）
    chunk_index  INTEGER NOT NULL DEFAULT 0, -- 块序号（同一文档内）
    source_file  VARCHAR(255),               -- 来源文件
    course_id    INTEGER,                   -- 所属课程 ID
    chapter      VARCHAR(100),              -- 章节信息
    created_at   TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- HNSW 索引（推荐，检索性能高）
CREATE INDEX ON knowledge_point_embeddings
USING hnsw (embedding vector_cosine_ops)
WITH (m = 16, ef_construction = 64);

-- 注释
COMMENT ON TABLE knowledge_point_embeddings IS '知识点 embedding 存储表';
```

> **向量维度说明**：
> - `text-embedding-ada-002`：1536 维
> - `text-embedding-3-small`：1536 维（可降至 256/512/1024）
> - `BGE-M3`：1024 维
> - 当前 Demo 配置为 768 维，可根据实际模型调整

**向量存储操作类**：

```python
# backend/app/rag/vector_store.py
import json
from typing import List, Optional
from sqlalchemy import text
from sqlalchemy.ext.asyncio import AsyncSession

class VectorStore:
    """向量存储操作类"""
    
    def __init__(self, db_session: AsyncSession, embedding_service):
        self.db = db_session
        self.embedding_service = embedding_service
    
    async def insert_chunks(
        self,
        kp_id: int,
        chunks: List[dict],
        course_id: int = None
    ) -> int:
        """
        批量插入文本块及其 embedding
        
        Args:
            kp_id: 知识点 ID
            chunks: [{content, chunk_index, source, ...}, ...]
            course_id: 课程 ID
        
        Returns:
            插入的块数量
        """
        texts = [c["content"] for c in chunks]
        embeddings = await self.embedding_service.embed(texts)
        
        for chunk, embedding in zip(chunks, embeddings):
            embedding_json = json.dumps(embedding)
            await self.db.execute(
                text("""
                    INSERT INTO knowledge_point_embeddings
                        (kp_id, content_chunk, embedding, chunk_index, source_file, course_id)
                    VALUES
                        (:kp_id, :content, :embedding, :chunk_index, :source, :course_id)
                """),
                {
                    "kp_id": kp_id,
                    "content": chunk["content"],
                    "embedding": embedding_json,
                    "chunk_index": chunk["chunk_index"],
                    "source": chunk.get("source", ""),
                    "course_id": course_id,
                }
            )
        
        await self.db.commit()
        return len(chunks)
    
    async def similarity_search(
        self,
        query: str,
        top_k: int = 5,
        kp_id: int = None,
        course_id: int = None
    ) -> List[dict]:
        """
        余弦相似度检索
        
        Args:
            query: 查询文本
            top_k: 返回 Top-K 结果
            kp_id: 可选，限定知识点 ID
            course_id: 可选，限定课程 ID
        
        Returns:
            检索结果列表，每项包含 content, similarity, metadata
        """
        # 生成查询向量
        query_embedding = await self.embedding_service.embed([query])
        query_vec = json.dumps(query_embedding[0])
        
        # 构建查询
        sql = """
            SELECT
                embedding_id,
                kp_id,
                content_chunk,
                1 - (embedding <=> :query_vec::vector) AS similarity,
                chunk_index,
                source_file,
                chapter
            FROM knowledge_point_embeddings
            WHERE 1=1
        """
        params = {"query_vec": query_vec, "top_k": top_k}
        
        if kp_id:
            sql += " AND kp_id = :kp_id"
            params["kp_id"] = kp_id
        
        if course_id:
            sql += " AND course_id = :course_id"
            params["course_id"] = course_id
        
        sql += """
            ORDER BY embedding <=> :query_vec::vector
            LIMIT :top_k
        """
        
        result = await self.db.execute(text(sql), params)
        rows = result.fetchall()
        
        return [
            {
                "embedding_id": row.embedding_id,
                "kp_id": row.kp_id,
                "content": row.content_chunk,
                "similarity": round(row.similarity, 4),
                "chunk_index": row.chunk_index,
                "source": row.source_file,
                "chapter": row.chapter,
            }
            for row in rows
        ]
```

### 3.2 检索器核心逻辑

```python
# backend/app/rag/retriever.py
from typing import List, Optional
from .vector_store import VectorStore
from .embedding_service import BaseEmbeddingService

class RAGRetriever:
    """RAG 检索器"""
    
    def __init__(
        self,
        vector_store: VectorStore,
        embedding_service: BaseEmbeddingService
    ):
        self.vector_store = vector_store
        self.embedding = embedding_service
    
    async def retrieve(
        self,
        query: str,
        top_k: int = 5,
        kp_id: int = None,
        course_id: int = None,
        min_similarity: float = 0.5
    ) -> dict:
        """
        执行 RAG 检索
        
        Args:
            query: 用户查询文本
            top_k: 返回 Top-K 结果
            kp_id: 限定知识点 ID（可选）
            course_id: 限定课程 ID（可选）
            min_similarity: 最低相似度阈值
        
        Returns:
            {
                "query": str,
                "retrieved_chunks": List[dict],
                "context": str,  # 拼接后的上下文
                "retrieval_stats": {
                    "total": int,
                    "above_threshold": int,
                    "avg_similarity": float
                }
            }
        """
        chunks = await self.vector_store.similarity_search(
            query=query,
            top_k=top_k,
            kp_id=kp_id,
            course_id=course_id
        )
        
        # 过滤低相似度结果
        filtered_chunks = [c for c in chunks if c["similarity"] >= min_similarity]
        
        # 构建上下文字符串
        context_parts = []
        for i, chunk in enumerate(filtered_chunks, 1):
            source = chunk.get("source") or "未知来源"
            chapter = chunk.get("chapter") or ""
            context_parts.append(
                f"[参考文档 {i}] 来源：{chapter}{source}, chunk #{chunk['chunk_index']}\n"
                f"{chunk['content']}"
            )
        
        context = "\n\n".join(context_parts)
        
        # 统计信息
        similarities = [c["similarity"] for c in chunks]
        stats = {
            "total": len(chunks),
            "above_threshold": len(filtered_chunks),
            "avg_similarity": round(sum(similarities) / len(similarities), 4) if similarities else 0.0,
            "max_similarity": round(max(similarities), 4) if similarities else 0.0,
        }
        
        return {
            "query": query,
            "retrieved_chunks": filtered_chunks,
            "context": context,
            "retrieval_stats": stats,
        }
    
    def build_generation_prompt(
        self,
        query: str,
        resource_type: str,
        difficulty: str,
        context: str
    ) -> str:
        """
        构建资源生成的 Prompt，注入检索到的上下文
        
        Args:
            query: 知识点查询
            resource_type: 资源类型（讲义/习题/案例/测验等）
            difficulty: 难度等级
            context: 检索到的上下文片段
        
        Returns:
            完整的 Prompt 字符串
        """
        prompt = f"""你是一位专业的课程助教。请根据以下参考文档，为学生生成学习资源。

## 知识点查询
{query}

## 资源类型
{resource_type}

## 难度要求
{difficulty}

## 参考文档（必须基于以下内容生成，禁止凭空编造）
---
{context}
---

## 生成要求
1. 生成内容必须严格基于上述参考文档，不得添加文档中不存在的信息
2. 每当使用或转述参考文档中的内容时，必须在句尾用 [来源：xxx] 的格式标注来源
3. 如果参考文档无法完全覆盖查询内容，明确说明"此部分为基于现有知识的推断"
4. 生成 {resource_type} 类型的学习资源，难度适合 {difficulty} 水平的学生

## 输出格式
{self._get_format_template(resource_type)}
"""
        return prompt
    
    def _get_format_template(self, resource_type: str) -> str:
        templates = {
            "讲义": "## 标题\n\n### 学习目标\n...\n\n### 正文内容（带引用标注）\n...\n\n### 练习题\n...",
            "习题": "## 习题集\n\n1. [题目] ... [答案] ... [来源：xxx]\n2. ...",
            "案例": "## 案例描述\n...\n\n## 分析与解答（带引用标注）\n...",
            "测验": "## 测验题目\n\n1. [题型] 题目内容\n   - 选项/答案\n   - [知识点来源：xxx]",
        }
```

### 4.2 证据锁定（Evidence Locking）

**核心原则**：生成内容中的每一个事实性陈述，必须能够溯源到知识库中的具体文档片段。

```python
# backend/app/rag/trust_scorer.py
import re
from typing import List, Tuple

class AntiHallucinationScorer:
    """防幻觉评分器"""
    
    CITATION_PATTERN = re.compile(r"\[来源[：:]([^\]]+)\]")
    
    def calculate_trust_score(
        self,
        generated_content: str,
        retrieved_chunks: List[dict]
    ) -> dict:
        """
        计算可信度评分
        
        Args:
            generated_content: LLM 生成的内容
            retrieved_chunks: 检索到的文档片段
        
        Returns:
            {
                "trust_score": float,          # 可信度评分 0-1
                "total_paragraphs": int,        # 生成内容的段落数
                "cited_paragraphs": int,        # 带引用的段落数
                "uncited_paragraphs": int,      # 未引用的段落数
                "citations": List[dict],       # 引用详情
                "risk_level": str,              # risk/low/medium/high
                "risk_alert": str,              # 风险提示文本
            }
        """
        paragraphs = self._split_paragraphs(generated_content)
        total_paragraphs = len(paragraphs)
        
        # 提取引用
        citations = self._extract_citations(generated_content)
        cited_paragraphs = len(set(c["paragraph_idx"] for c in citations))
        
        # 计算覆盖率
        coverage = cited_paragraphs / total_paragraphs if total_paragraphs > 0 else 0.0
        
        # 检测推断性内容（无引用但有实质内容的段落）
        uncited_content = []
        for i, para in enumerate(paragraphs):
            if not any(c["paragraph_idx"] == i for c in citations):
                stripped = para.strip()
                if len(stripped) > 20 and not stripped.startswith("#"):  # 排除标题
                    uncited_content.append({
                        "paragraph_idx": i,
                        "preview": stripped[:100]
                    })
        
        # 风险评估
        risk_level, risk_alert = self._assess_risk(coverage, uncited_content)
        
        return {
            "trust_score": round(coverage, 2),
            "total_paragraphs": total_paragraphs,
            "cited_paragraphs": cited_paragraphs,
            "uncited_paragraphs": len(uncited_content),
            "uncited_content": uncited_content,
            "citations": citations,
            "risk_level": risk_level,
            "risk_alert": risk_alert,
        }
    
    def _split_paragraphs(self, text: str) -> List[str]:
        """按段落分割文本"""
        return [p.strip() for p in re.split(r"\n\s*\n", text) if p.strip()]
    
    def _extract_citations(self, text: str) -> List[dict]:
        """提取所有引用标注"""
        citations = []
        paragraphs = self._split_paragraphs(text)
        
        for para_idx, para in enumerate(paragraphs):
            matches = self.CITATION_PATTERN.findall(para)
            for match in matches:
                citations.append({
                    "paragraph_idx": para_idx,
                    "source": match.strip(),
                })
        
        return citations
    
    def _assess_risk(self, coverage: float, uncited_content: List[dict]) -> Tuple[str, str]:
        """评估风险等级"""
        if coverage >= 0.8:
            return "low", ""
        elif coverage >= 0.5:
            return "medium", ""
        elif coverage >= 0.3:
            return "high", (
                "⚠️ 此部分内容引用覆盖率较低（{:.0%}），"
                "部分内容为 AI 推断生成，建议教师复核后使用。"
            ).format(coverage)
        else:
            return "critical", (
                "🚨 警告：此部分内容引用覆盖率极低（{:.0%}），"
                "大部分内容为 AI 推断，可能存在知识错误或幻觉，"
                "强烈建议教师仔细复核后再发布给学生。"
            ).format(coverage)
    
    def format_with_citations(
        self,
        content: str,
        trust_score: dict
    ) -> str:
        """
        为内容追加引用格式和风险提示
        """
        result = content
        
        # 追加风险提示（如果需要）
        if trust_score["risk_level"] in ("high", "critical"):
            alert = trust_score["risk_alert"]
            result += f"\n\n---\n{alert}"
        
        # 追加引用来源汇总（如果篇幅较长）
        if trust_score["cited_paragraphs"] > 0:
            citation_sources = set(c["source"] for c in trust_score["citations"])
            sources_text = "\n".join(f"- {s}" for s in citation_sources)
            result += f"\n\n---\n**引用来源**：\n{sources_text}"
        
        return result
```

### 4.3 引用格式规范

生成内容中的引用必须遵循以下格式：

| 格式 | 示例 | 说明 |
|------|------|------|
| 文档来源 | `[来源：教材第3章 SQL查询基础]` | 教材章节 |
| 课件来源 | `[来源：课件 Chapter4-连接查询]` | 课件文件 |
| 习题来源 | `[来源：第5章习题集 P23]` | 习题集页码 |
| 推断说明 | `（基于现有知识的推断）` | 无法溯源时 |

**正确示例**：
```
INNER JOIN 返回两表满足 ON 条件的匹配记录。
[来源：教材第3章 SQL查询基础]

LEFT JOIN 与 INNER JOIN 的主要区别在于 LEFT JOIN 会保留左表全部记录，
即使右表中没有匹配行也会显示 NULL 值。
[来源：课件 Chapter4-连接查询]
```

**错误示例**（应避免）：
```
INNER JOIN 是数据库中最常用的连接类型。（无引用 ✗）

根据 SQL 标准规定，JOIN 操作的优先级...（无引用 ✗）
```

## 七、技术选型说明

| 技术选型 | 选择理由 |
|---------|---------|
| **PostgreSQL + pgvector** | 在已有 MySQL 的基础上扩展，pgvector 提供高效的向量检索；支持 SQL JOIN 操作，与业务表无缝结合 |
| **HNSW 索引** | 平衡检索精度和速度，`m=16, ef_construction=64` 是生产级配置 |
| **text-embedding-3-small** | OpenAI 最新模型，性价比高，支持维度压缩 |
| **BGE-M3** | 开源可选方案，支持多语言（中文优化），可本地部署 |
| **Chunk Size = 500** | 适合中文语义单元，保留足够的上下文又不至于太宽泛 |
| **余弦相似度** | 对向量长度不敏感，适合文本 embedding 检索 |
