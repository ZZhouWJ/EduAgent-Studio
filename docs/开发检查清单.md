# EduAgent Studio 开发与发布检查清单

> 适用基线：`main`，V2.1
>
> 最近核对：2026-07-17

本清单用于新功能合并、竞赛发布和部署变更。`[x]` 只代表 2026-07-17 当前代码基线已验证；发布时必须在目标环境重新执行，不直接沿用历史勾选。

## 1. 变更准入

- [ ] 需求已转换为可观测行为、权限边界和失败条件。
- [ ] 已阅读相关 Router、Service、Repository、数据表和前端 API 类型。

## 2. 后端

- [x] FastAPI Router 不直接编写业务 SQL。
- [x] Service 在读写前执行角色和课程/资源/会话所有权校验。
- [x] Repository 使用参数化 SQL，动态 `IN` 只生成占位符数量。
- [x] 跨表写入在一个事务中完成，检查 `affected_rows` 和回滚分支。
- [x] 错误响应不向客户端返回堆栈、SQL、密钥或供应商内部错误。
- [x] 生产配置强制随机 JWT/API Key 密钥、明确 CORS 和非 Mock Provider。
- [ ] 新增 API 已覆盖成功、验证失败、无权、越权、不存在和内部异常测试。

## 3. 前端

- [x] React 页面通过统一 API 客户端请求真实后端，主流程无纯前端假成功。
- [x] 认证状态由 Zustand store 统一管理，会话失效进入登录流程。
- [x] Markdown/HTML 在渲染前消毒。
- [x] 学生、教师、管理员所有主路由在 390px 和 1440px 视口下可用。
- [x] 可见图标按钮有可读名称，焦点状态可见。
- [x] 表格、图谱、长代码和对话内容不造成整页横向溢出。
- [ ] 新页面已实现 loading、empty、error、retry、disabled 和成功反馈状态。
- [ ] 新交互已使用键盘走通，弹窗具有焦点管理和 Escape 关闭行为。

- [x] Compose 按文件名顺序挂载所有生产 MySQL 迁移。
- [x] `07_test_queries.sql`、`08_insert_prompt_templates.sql` 和历史 `11_postgresql_migration.sql` 不进入自动初始化。
- [x] `32_seed_course_knowledge_base.sql` 导入 9 个 CS301 chunk 和 9 条已确认知识点关联。

- [ ] 迁移前已备份目标数据库，迁移后已验证表、索引、视图、种子数据与关键数量。

## 5. AI、RAG 与审核

- [x] 教师资源生成图包含诊断、规划、生成、评测、审核建议和最多 3 次返工。
- [x] LangGraph checkpoint 持久化到 `APP_DATA_DIR/agent_workflows.sqlite3`。
- [x] Tutor Supervisor 最多 8 步，工具 ID、输入 schema、超时和失败状态可追踪。
- [x] 教师搜索和 Agent RAG 共用 BM25 + 中文 2–4 字 n-gram 分词。
- [x] 资源引用只接受本次证据集中的整数 chunk ID，无证据时降级为草稿。
- [x] 资源与证据链在同一 MySQL 事务中保存。
- [x] 学生只推荐和显示 `approved` 资源。
- [x] LLM Gateway 扫描用户输入、模型正文和 tool arguments，命中时不执行工具。
- [ ] 新增 Agent/Tool 已定义输入上限、数据域、Provider 降级、证据、内容安全、成本和审核方式。
