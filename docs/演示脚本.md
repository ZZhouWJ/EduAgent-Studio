# 智学工坊 EduAgent Studio — 演示脚本

> **演示时长**：约 15 分钟
> **演示版本**：Phase 1 + Phase 2 交付版
> **演示对象**：评委 / 老师 / 同学
> **演示目标**：展示系统全流程，证明 A3 赛题 7 大要求均已覆盖

---

## 演示前准备

### 环境启动（3 分钟）

```bash
# 终端 1：启动后端（Mock 模式，无需数据库）
cd backend && python run.py
# 预期输出：Uvicorn running on http://0.0.0.0:8000

# 终端 2：启动前端
cd frontend && npm run dev
# 预期输出：VITE v5.x ready in xxx ms
```

> **注意**：如果数据库未就绪，系统以 Mock 模式运行，所有接口返回预设数据，无需准备数据。

### 浏览器访问

```
http://localhost:5173
```

### 第四步：智能体工作台 — 核心演示（约 5 分钟）

> **这是本系统最核心的功能演示**，请放慢节奏、详细讲解。

**操作**：点击左侧菜单「智能体工作台」

**屏幕预期**：智能体工作台页面，左侧 5 个智能体卡片，右侧配置区

**讲解要点**：
> 「这是我们系统的核心——多智能体协作工作台。系统包含 5 类智能体，均基于 LangGraph 工作流编排：
> 1. 学习诊断智能体：分析学生薄弱点
> 2. 资源规划智能体：生成学习路径
> 3. 资源生成智能体：生成具体学习资源
> 4. 评测反馈智能体：分析学习效果并更新画像
> 5. 教师审核辅助智能体：为教师审核提供质量建议」

**操作**：按以下配置填写表单

| 配置项 | 选择值 |
|--------|--------|
| 选择学生 | 李明 |
| 选择课程 | 数据库系统原理 |
| 目标知识点 | SQL多表连接 |
| 资源类型 | 讲义 |
| 难度 | 进阶 |

**讲解要点**：
> 「我们为学生李明生成一份「SQL多表连接」的进阶讲义。系统将自动调度 5 个智能体协作完成。」

**操作**：点击「开始生成个性化学习资源」

**屏幕预期**：执行链路图逐步点亮（5 个节点依次变为绿色，约 3-5 秒）

**讲解要点**：
> 「执行链路图实时展示 5 个智能体的执行状态：
> - 第一步：学习诊断智能体分析李明的画像，识别薄弱点
> - 第二步：资源规划智能体生成学习路径（讲义结构、大纲）
> - 第三步：资源生成智能体生成具体讲义内容
> - 第四步：评测反馈智能体分析内容质量
> - 第五步：教师审核辅助智能体提供质量建议和修改建议」

> **重要提示**：每个节点耗时约 0.5-1 秒（Mock 模式），真实 LLM 模式下约 5-15 秒。

**屏幕预期**：执行完成后，显示「执行完成！」，右侧展示生成的讲义正文

**讲解要点**：
> 「我们看到一份完整的「SQL多表连接专题讲义」已生成，内容包含：
> - 讲义标题、难度、目标知识点
> - 内连接、外连接、左连接、右连接的详细讲解
> - 每种连接的语法、示例、练习题」

**操作**：点击「保存到学习资源库」

**屏幕预期**：弹出输入框，输入资源标题「SQL多表连接专题讲义（进阶）」，点击确认

## 视频录制注意事项

1. **分辨率**：推荐 1920×1080，全屏录制
2. **语速**：智能体演示环节放慢，让评委看清执行链路
3. **提前准备**：演示前确认 `npm run dev` 和 `python run.py` 均正常运行
4. **Mock 模式**：无需真实数据库即可完整演示全部功能
5. **备选账号**：准备 2-3 个账号切换，展示不同角色视角

## 常见问题 & 排查

| 问题 | 解决方案 |
|------|---------|
| 前端访问 `localhost:5173` 白屏 | 检查 `cd frontend && npm install` 是否完整 |
| 后端启动报错 `ModuleNotFoundError` | `cd backend && pip install -r requirements.txt` |
| 接口返回 401 未授权 | 检查 Token 是否过期，重新登录 |
| 智能体执行链路卡住 | Mock 模式正常，检查网络是否可访问 LLM API |
| ECharts 图表不显示 | 确认 `npm install echarts` 已执行 |
