## 二、核心功能说明

### 2.1 RAG 课程知识库（轻量 Demo）

**架构**：`document_loader` → `retriever(BM25)` → `rag_service` → `diagnosis_agent`

**数据规模**：12 篇课程文档，覆盖以下知识点：
- DB001 关系模型基础（含 ER 图设计）
- DB002 SQL 基本查询（含子查询与集合运算）
- DB003 数据定义 DDL
- DB005 SQL 多表连接（含优化建议）
- DB008 事务与并发控制（含 ACID、隔离级别、锁机制）
- DB012 数据库范式（1NF~BCNF）
- DB015 索引与查询优化（B+Tree、最左前缀原则）

**检索验证**：
```
Q: 事务隔离级别 ACID 脏读 不可重复读
  → db008-2 | 事务隔离级别 — 四种级别详解 | score=7.67

Q: 数据库范式 1NF 2NF 3NF
  → db012-1 | 数据库范式 — 1NF/2NF/3NF/BCNF | score=14.52

Q: 索引优化 B+Tree 查询优化
  → db015-1 | 索引与查询优化 — B+Tree 索引原理 | score=5.90

Q: SQL多表连接 事务隔离级别
  → db005-1 | SQL 多表连接 — JOIN 类型详解 | score=3.32
```

**创新点 3 完整化**：RAG 检索为 LLM Agent 提供有据可查的课程知识背景，解决幻觉问题。

### 2.2 对话式画像构建界面

- 点击「编辑画像」按钮弹出对话框
- 可修改：学习目标（textarea）、当前基础（textarea）、兴趣方向（多选+自由输入）、资源偏好（多选+自由输入）、每周学习时间（slider）
- 调用 `PUT /api/profiles/{id}` 保存，保存后刷新详情

### 2.3 学习路径图谱可视化

**数据流**：`GET /learning/courses/{id}/learning-path` → `LearningRepository.get_learning_path()` → 返回 `{nodes, edges, summary}`

**节点设计**：
- 颜色：已掌握（绿 #67c23a ≥70%）、学习中（橙 #e6a23c 40%~70%）、薄弱（红 #f56c6c <40%）、未学习（灰 #909399）
- 大小：随难度级别放大（基础 60px + 难度×10px）
- 显示：知识点名称 + 掌握度百分比

**边设计**：`parent_kp_id → child kp_id`，标注「前置」关系

**交互**：Force 布局，支持拖拽、缩放、点击 tooltip 显示详情

### Top 2：PostgreSQL + pgvector 向量库初始化
当前 RAG 使用轻量 BM25 实现，pgvector 迁移脚本已准备好（`database/pgvector/`）。若要使用真实 embedding：
1. 执行 `database/pgvector/01_enable_pgvector.sql`

3. 部署 PostgreSQL Docker 服务
4. 替换 `rag_service.py` 中的 BM25 检索为向量相似度检索
