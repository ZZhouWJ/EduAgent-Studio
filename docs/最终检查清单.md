2. **用户登录测试**：`POST /api/auth/login` 返回有效 Token
3. **项目 CRUD 测试**：创建、查询、更新、软删除项目
4. **任务 CRUD 测试**：创建任务（`title` + `task_type_id`），自动创建主分支
5. **分支管理测试**：创建分支、查看分支列表
6. **输出版本测试**：查看输出版本列表、查看版本详情
7. **AI 生成测试**：`POST /api/tasks/{id}/generate`（需 Mock 模型数据）
8. **输出编辑测试**：`PUT /api/outputs/{id}` 含 `lock_version`
9. **批注测试**：`POST /api/outputs/{id}/comments`
10. **审核流程测试**：提交审核 + 完成审核（评分 0-10）
11. **成果采用测试**：`POST /api/outputs/{id}/adopt`
12. **分支合并测试**：`POST /api/tasks/{id}/branches/merge`
13. **统计接口测试**：7 个统计接口返回有效数据
14. **前端完整流程测试**：登录 → 创建项目 → 创建任务 → AI 生成 → 审核 → 成果采用
15. **前端 `npm run build`**：构建成功，无 TypeScript 编译错误
