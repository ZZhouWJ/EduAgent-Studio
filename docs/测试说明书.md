# EduAgent Studio 测试说明书

> **项目名称**：基于大模型的个性化资源生成与学习多智能体系统开发
>
> **版本**：v1.0
>
> **编写日期**：2026-06-12

---

## 1. 概述

### 1.1 项目简介

EduAgent Studio 是一个基于大模型的个性化学习资源生成与多智能体协作系统。系统采用 FastAPI 后端 + Vue3 前端架构，围绕学生画像、学习资源生成、教师审核等核心场景，通过多智能体工作流（诊断 → 规划 → 生成 → 评测 → 审核）实现自动化学习资源生产。

### 1.2 测试范围

| 测试类型 | 说明 |
|---------|------|
| 接口测试 | 后端 RESTful API 功能与边界验证 |
| 页面功能测试 | 前端核心页面交互与数据渲染 |
| 智能体工作流测试 | LangGraph 多智能体协作链路验证 |
| 数据库测试 | SQL 脚本执行与数据完整性验证 |

### 1.3 测试环境

- **后端**：Python 3.11+ / FastAPI / MySQL 8.0+（需开启 `ONLY_FULL_GROUP_BY`）
- **前端**：Node.js 20+ / Vite / Vue 3.5 / Element Plus
- **数据库**：MySQL 8.0（含 pgvector 扩展用于向量检索场景）
- **AI 能力**：支持 Mock 模式（本地模拟 LLM）和真实 LLM 模式（MiniMax / OpenAI Compatible）
- **测试账号**：
  - 管理员：`admin` / `Admin@123456`
  - 教师：`teacher01` / `Teacher@123`
  - 学生：`student01` / `Student@123`

| 字段 | 内容 |

| **所属模块** | 认证（/api/auth） |
| **测试目标** | 验证使用正确用户名和密码登录成功，返回有效 Token |
| **前置条件** | 用户 `admin` 存在于数据库中，状态为 `active` |

```bash
# 登录获取 Token
TOKEN=$(curl -s -X POST http://localhost:8000/api/auth/login \

  | jq -r '.data.token')

# 获取画像列表
curl -s http://localhost:8000/api/profiles/ \
  -H "Authorization: Bearer $TOKEN" | jq .
```
