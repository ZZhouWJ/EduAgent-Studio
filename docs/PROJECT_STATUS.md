## 2. 核心闭环

```text
教师维护课程与知识库
  -> 学生对话构建并确认学习画像
  -> 教师针对学生与知识点发起多智能体生成
  -> 诊断/规划/生成/评测/审核建议/可选修订
  -> 课程证据引用和可信度校验
  -> 教师保存草稿、提交审核并发布
  -> 学生按路径学习、完成任务并提交反馈
  -> 掌握度、画像、路径和资源推荐动态更新
  -> 教师与管理员在分析/审计/成本看板复核效果
```

学生另有 Tutor 对话式主入口，Tutor Supervisor 根据问题自动调用课程检索、讲解、练习、代码、思维导图、PPT、图像和语音工具。

## 3. 角色功能

### 3.1 学生端

- AI 学习辅导：对话流、工具进度、Markdown、Mermaid、代码和多模态内容块。
- 学习中心：课程进度、待办任务、推荐资源和快捷入口。
- 学习画像：12 维特征、掌握度、对话抽取确认和更新历史。
- 学习路径：交互式图谱、节点状态和学习顺序。
- 任务与资源：任务进度持久化、已审核个性化资源和资源详情。
- 反馈与报告：测验、自评、疑问反馈、掌握度和学习趋势。

### 3.2 教师端

- 课程、学生、知识点和任务管理。
- PDF、DOCX、PPTX 和文本课程材料上传、解析、重解析、检索和知识点匹配。
- 多智能体工作台：选择学生、知识点、目标、难度和资源类型，实时呈现执行轨迹。
- 资源工厂与教师审核：草稿、待审、通过、退回、审核记录和证据链。
- 学情分析：掌握度分布、薄弱知识点、活跃任务和审核质量。

### 3.3 管理端

- 用户、角色和课程归属管理。
- 模型供应商、加密凭证、智能体信息和 Prompt 版本管理。
- 调用、Token、成本、操作、登录与审核日志。
- 事实一致性、引用覆盖率、小时调用上限和敏感内容检测开关。
- 月度预算与成本告警配置。

## 4. 智能体和 AI 能力

### 4.1 教师资源生成图

| 节点 | 职责 |
| --- | --- |
| Diagnosis Agent | 读取学生画像、掌握度和历史反馈，识别薄弱点 |
| Planning Agent | 规划知识点顺序、资源组合和学习时长 |
| Resource Generation Agent | 优先检索已确认课程证据，生成个性化资源 |
| Assessment Agent | 检查内容和学习目标，给出质量反馈 |
| Teacher Review Agent | 给出事实、难度、完整性和教学使用建议 |
| Revision | 质量低于阈值时限次修订并重新审核 |

生成类型包括讲义、思维导图、练习题、代码实操案例、PPT 大纲、视频/动画脚本、实验报告、错题解析和学习卡片。

### 4.2 Tutor Supervisor

Tutor 将学生画像和课程检索结果注入系统上下文。支持模型原生 tool calling 和无 tool calling 时的意图路由，且会保留工具启动、完成、失败和总耗时轨迹。

图像生成与语音合成已连接讯飞官方 API，PPT Agent 会生成结构化幻灯片并支持导出可编辑 PPTX。外部凭证缺失时显式降级，不返回伪造结果。

### 4.3 防幻觉与内容安全

- 仓库包含 9 章 CS301 课程文档集，数据库迁移会生成 9 个整数 chunk 和已确认知识点绑定。
- 生成前优先读取课程证据，生成后校验引用 ID，保存时写入资源证据链。
- 无引用或引用无效时降低可信等级，资源只能以草稿进入教师审核。
- LLM Gateway 在调用前扫描用户输入，调用后扫描模型正文和工具参数。
- 内容安全命中时不返回原文、不执行工具，日志只记录风险类别。

## 8. 后续修改规则

1. 修改前先以代码和测试验证本文档中的状态，不要恢复旧的 Vue/PostgreSQL/Stub 描述。
2. 新功能必须同时更新 API 合约、权限范围、测试和运行文档。
3. 不得在仓库中提交真实密码、JWT 密钥、模型 API Key 或已解密凭证。
4. 任何新的资源生成入口都必须通过课程证据、内容安全、教师审核和数据域权限。
5. 每次状态变更都要更新「最近核对」日期和「验证基线」，删除与当前实现冲突的描述。
