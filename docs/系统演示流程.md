# 系统演示流程

> 本文档描述智研协作 AI 项目质量审计系统的课程答辩演示流程。每一步标明涉及的后端接口、截图建议和演示前置条件。
> 适用于已成功配置 MySQL 数据库、Windows 本地环境的演示场景。
> 如当前环境无 MySQL，请标注"前置条件：需 Windows MySQL 环境"，跳过无法实际执行的步骤。

---

## 演示前置条件

演示前需确保以下环境就绪：

1. **MySQL 数据库**：已执行 `database/01_create_tables.sql` 至 `database/07_test_queries.sql`
2. **后端服务**：FastAPI 已启动（`cd backend && python run.py`），监听 `http://127.0.0.1:8000`
3. **前端服务**：Vite 已启动（`cd frontend && npm run dev`），监听 `http://localhost:5173`
4. **测试账号**：admin / Admin@123456（或其他数据库中已导入的账号）
5. **浏览器**：Chrome / Edge，建议窗口最大化便于截图

> ⚠️ **环境限制说明**：当前 Ubuntu/WSL 环境无法连接 Windows MySQL 数据库，以下流程涉及数据库读写的步骤需在 Windows 本地环境执行。演示时请在本地 Windows 环境中补做。

## 演示时长建议

| 步骤 | 内容 | 建议时长 |
|------|------|----------|
| 0-2 | 环境确认+登录 | 1 分钟 |
| 3-5 | 项目+任务创建 | 2 分钟 |
| 6-10 | 任务详情+AI生成+编辑+批注 | 3 分钟 |
| 11-13 | 审核中心+审核流程 | 2 分钟 |
| 14-16 | 成果库+采用 | 2 分钟 |
| 17 | 统计看板 | 1 分钟 |
| 合计 | — | 约 11 分钟 |

**建议**：整个演示控制在 10-15 分钟内，保留 5 分钟答辩时间。
