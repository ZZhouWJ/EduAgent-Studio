# 系统演示流程

> 本文档为智研协作 AI 项目质量审计系统的课程答辩演示流程指南。建议按以下顺序执行，每一步均标注了截图建议和涉及的后端接口。
> 演示时长预估：15-20 分钟。

---

## 演示前置条件

在开始演示前，请确保已完成以下准备工作：

### 环境准备

1. **数据库已初始化**：在 MySQL 中执行了 `database/01_create_database.sql` 到 `database/07_test_queries.sql`。
2. **后端已启动**：`cd backend && python run.py`，终端显示 `Application startup complete`。
3. **前端已启动**：`cd frontend && npm run dev`，浏览器可访问 http://localhost:5173。
4. **测试数据已就绪**：数据库 `04_insert_initial_data.sql` 中的测试账号可用。

## 演示流程

### 第一部分：系统登录与首页概览（约 2 分钟）

#### 步骤 1：展示登录页

1. 打开浏览器，访问 http://localhost:5173
2. 展示登录页 UI（智研协作 Logo、系统名称）
3. **截图**：登录页全屏截图

**涉及接口**：`/api/auth/login`

---

#### 步骤 2：登录系统

1. 输入用户名 `admin` 和密码 `Admin@123456`
2. 点击登录，观察页面跳转
3. 登录成功后进入首页
4. **截图**：登录成功后的首页

**涉及接口**：
- `POST /api/auth/login`
- `GET /api/auth/me`
- `GET /api/statistics/overview`（首页数据加载）

---

#### 步骤 3：展示首页

1. 展示左侧导航栏（项目空间、任务与版本、审核中心、成果库、统计看板、模型管理）
2. 展示首页统计卡片（项目数、任务数、审核数等）
3. 展示流程引导卡片（创建项目 → 创建任务 → AI 生成 → 提交审核 → 采用成果）
4. **截图**：首页全屏截图

---

### 第二部分：项目空间与成员管理（约 3 分钟）

#### 步骤 4：进入项目空间

1. 点击左侧导航"项目空间"
2. 展示项目列表（可包含初始示例项目）
3. **截图**：项目列表页面

**涉及接口**：`GET /api/projects`

---

#### 步骤 5：创建新项目

1. 点击"创建项目"按钮
2. 填写项目名称（如"数据库课程报告项目"）、项目类型（课程项目）、描述
3. 提交创建
4. 在项目列表中确认新项目出现
5. **截图**：创建项目弹窗 + 项目列表更新

**涉及接口**：
- `POST /api/projects`
- `GET /api/projects`

---

#### 步骤 6：查看项目详情

1. 点击项目名称进入项目详情页
2. 展示项目信息 Tab（基本信息、成员列表、任务列表）
3. 切换到成员列表 Tab，展示角色（Owner、Leader、Member）
4. **截图**：项目详情页（含成员列表）

**涉及接口**：
- `GET /api/projects/{projectId}`
- `GET /api/projects/{projectId}/members`
- `GET /api/projects/{projectId}/tasks`

---

### 第三部分：任务与版本管理（约 5 分钟）

#### 步骤 7：创建任务

1. 在项目详情页，点击"创建任务"按钮
2. 填写任务信息（标题、任务类型、描述、指派人、优先级、截止日期）
3. 提交创建
4. **截图**：创建任务弹窗

**涉及接口**：`POST /api/projects/{projectId}/tasks`

---

#### 步骤 8：进入任务详情

1. 从项目详情页的任务列表中点击任务，进入任务详情页
2. 展示任务基本信息
3. 展示分支列表（默认主分支）
4. 展示输出版本列表（初始为空）
5. **截图**：任务详情页（分支 + 版本区域）

**涉及接口**：
- `GET /api/tasks/{taskId}`
- `GET /api/tasks/{taskId}/branches`
- `GET /api/tasks/{taskId}/outputs`

---

#### 步骤 9：调用 AI 生成

1. 在任务详情页找到"AI 生成"面板
2. 选择模型（可多选，如 DeepSeek-V3、GPT-4o）
3. 输入提示词（如"生成需求分析初稿"）
4. 点击"生成"按钮
5. 观察返回的 Mock 生成结果
6. **截图**：AI 生成面板 + 生成结果

**涉及接口**：
- `POST /api/tasks/{taskId}/generate`
- `GET /api/tasks/{taskId}/outputs`

> **注**：当前使用 Mock 机制，返回模拟数据。演示时请说明这是 Mock 返回，扩展真实 API 时仅需替换 `ModelAdapter`。

---

#### 步骤 10：查看输出版本

1. 在版本列表中找到刚生成的版本
2. 点击版本卡片查看完整输出内容
3. 展示版本时间线（基于 parent_output_id 的版本链）
4. **截图**：输出详情 + 版本时间线

**涉及接口**：
- `GET /api/outputs/{outputId}`
- `GET /api/outputs/{outputId}/timeline`

---

### 第四部分：人工编辑与批注（约 3 分钟）

#### 步骤 11：编辑输出

1. 在输出详情页面，点击"编辑"按钮
2. 修改输出内容（如补充背景分析、修正格式）
3. 点击"另存为新版本"
4. 在版本列表中确认新版本出现
5. **截图**：编辑弹窗 + 新版本出现

**涉及接口**：
- `PUT /api/outputs/{outputId}`
- `POST /api/outputs/{outputId}/save-as`

---

#### 步骤 12：添加批注

1. 在输出详情页面，点击"添加批注"按钮
2. 输入批注内容（如"第三段逻辑不够清晰"）
3. 提交批注
4. 在批注列表中查看已添加的批注
5. **截图**：批注列表 + 批注状态

**涉及接口**：
- `POST /api/outputs/{outputId}/comments`
- `GET /api/outputs/{outputId}/comments`

---

### 第五部分：审核中心（约 3 分钟）

#### 步骤 13：提交审核

1. 在任务详情页或输出详情页，点击"提交审核"按钮
2. 填写提交说明（如"请审核需求分析初稿"）
3. 提交审核请求
4. **截图**：提交审核弹窗

**涉及接口**：`POST /api/outputs/{outputId}/submit-review`

---

#### 步骤 14：进入审核中心

1. 点击左侧导航"审核中心"
2. 展示待审核列表
3. 点击一条待审核记录，进入审核详情
4. 展示输出内容、问题标签选择、多维评分（准确性、完整性等）
5. **截图**：审核列表 + 审核详情页

**涉及接口**：
- `GET /api/reviews/pending`
- `GET /api/reviews/{requestId}`
- `GET /api/issue-tags`

---

#### 步骤 15：完成审核

1. 在审核详情页，选择问题标签（如"内容空洞"、"格式不规范"）
2. 对准确性、完整性、逻辑性、格式规范性、实用性各评 0-10 分
3. 填写审核意见
4. 选择审核结论（通过/不通过/需修改）
5. 点击"提交审核"
6. 返回审核列表，确认状态已更新
7. **截图**：评分弹窗 + 审核完成后的状态变化

**涉及接口**：`POST /api/reviews/{requestId}/complete`

---

### 第六部分：成果库（约 2 分钟）

#### 步骤 16：采用成果

1. 在审核通过的输出详情页，点击"采用为成果"按钮
2. 填写成果标题、类型（文档/代码/其他）、发布版本号、采用说明
3. 提交采用
4. **截图**：采用成果弹窗

**涉及接口**：`POST /api/outputs/{outputId}/adopt`

---

#### 步骤 17：查看成果库

1. 点击左侧导航"成果库"
2. 展示所有已采用的成果列表
3. 点击一条成果进入详情
4. 展示成果完整内容、采用说明、发布版本
5. **截图**：成果库列表 + 成果详情

**涉及接口**：
- `GET /api/artifacts`
- `GET /api/artifacts/{adoptedId}`

## 演示注意事项

1. **Mock 模型说明**：每次演示 AI 生成时，应主动说明当前使用 Mock 返回模拟数据，扩展真实模型 API 只需实现 `ModelAdapter` 接口。
2. **数据准备**：建议在演示前预先创建好一个项目、一条任务和一条输出，以便演示审核流程时更流畅。
3. **环境限制**：如果演示环境无法连接 MySQL，请跳过涉及数据库读写的步骤（如登录后的数据加载），改为展示代码和接口文档。
4. **截图命名**：建议按"模块_功能_序号.png"格式命名，如"01_登录页_全屏.png"。
