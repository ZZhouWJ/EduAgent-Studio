# A3 赛题适配说明

> 项目：智学工坊 EduAgent Studio
> 赛题：A3 - 基于大模型的个性化资源生成与学习多智能体系统开发
> 核对日期：2026-07-17
> 核对依据：赛题原文、当前 `main` 分支、运行数据库和端到端验证

## 1. 产品定位

EduAgent Studio 面向高校「数据库系统原理」课程，以「课程知识库 -> 学生画像 -> 学习诊断 -> 路径规划 -> 个性化资源生成 -> 教师审核 -> 学习与反馈 -> 画像更新」为主闭环。

产品同时提供三个角色空间：

- 学生端：对话式 AI 辅导、画像、学习路径、任务、推荐资源、反馈和学习报告。
- 教师端：课程与学生管理、知识库、多智能体工作台、资源审核、任务和学情分析。
- 管理端：用户与权限、模型配置、Prompt 版本、成本、治理和审计。

## 2. 赛题功能对应

| 赛题要求 | 当前实现 | 主要证据 |
| --- | --- | --- |

| 多智能体协同生成 | LangGraph 串联诊断、规划、生成、评测和教师审核辅助智能体；低质量时进入修订循环 | `backend/app/agents/workflow.py` |

| 学习效果评估加分项 | 跟踪任务进度、测验得分、自评和资源反馈，更新掌握度并在分析看板中呈现 | `learning_task_progress`、`learning_feedback_service.py`、`LearningAnalytics.tsx` |

## 3. 课程知识库与可追溯性

项目自建「数据库系统原理」课程文档集，在 `database/fixtures/database_system_principles.md` 中覆盖 9 个主题：

1. 数据库基本概念
2. 关系模型
3. SQL 基本查询
4. 多表连接与子查询
5. 索引与查询优化
6. 事务与 ACID
7. 并发控制与锁
8. 范式与反范式
9. 数据库设计 (E-R)

`32_seed_course_knowledge_base.sql` 将文档导入 `course_materials` 与 `course_material_chunks`，并建立 9 条已确认的 `kp_chunk_links`。资源生成前优先取课程证据，生成后校验 `[引用:chunk_id]`，保存资源时在同一事务内写入 `resource_evidence_links`。无有效证据时资源明确标为草稿，不会伪造高可信结论。

## 6. 外部能力运行前提

代码已实现讯飞星火、图像理解、图像生成、语音合成与 ChatDoc 的鉴权和调用封装。实际调用必须在部署环境配置有效的 `IFLYTEK_APP_ID`、`IFLYTEK_API_KEY`、`IFLYTEK_API_SECRET` 及相应服务权限。凭证未配置时，系统会显式降级并返回可理解的不可用状态，不伪造外部生成结果。
